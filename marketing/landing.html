LLM Wiki 工作流

源自 Karpathy 的 LLM Wiki 概念, 我们把它落地到法律行业, 这是国内首个实践。

lexprime-workflow.md 
# 每周日 02:00 自动巡检
def lint_workspace(wiki, raw_sources):
    issues = []

    # 1. 孤儿 Wiki: 无任何反向链接
    for page in wiki.pages:
        if page.backlinks == 0:
            issues.append("orphan", page)

    # 2. 过期法条: 已废止/修订
    for page in wiki.pages:
        if page.cites_law.expired:
            issues.append("outdated", page)

    # 3. 判例矛盾: 同一问题相反结论
    contradictions = wiki.find_contradictions()
    for c in contradictions:
        issues.append("conflict", c)

    # 4. 缺引用: Wiki 主张无源
    for claim in wiki.all_claims():
        if not claim.has_source:
            issues.append("unsourced", claim)

    return issues  # → 律师审核签字 → 生效

常见问题

AI 生成的判例准确吗? 律师要负责最终审核吗? ▼

LexPrime 严格遵循「AI 辅助、不替代律师」的产品原则。 所有 AI 生成的 Wiki 页和巡检建议都需要律师人工审核签字后才生效, AI 仅作为效率工具。 我们的健康度评分 (Health Score) 包含「未审核比例」指标, 提醒您持续审核。

律师执业数据如何保护? ▼

客户内容默认加密存储于中国大陆合规云服务商。 企业版支持私有化部署, 数据完全在律所内部。 所有访问都有审计日志, SSO + 双因素认证可选。

律所采购流程长, 有没有加速方式? ▼

我们推荐「个人律师先试用 → 拉同事 → 升级团队版」的渐进路径, 律所不必一次性采购。我们提供按席位月付, 无年付锁定。 5 席位以下的律所, 团队版月付即可。

支持哪些案由和地域? ▼

当前优化: 民事 (合同/侵权/家事/继承)、商事 (公司/知产/竞争)、刑事 (常见罪名)。 地域: 中国大陆 (最高人民法院 + 高级人民法院 + 中级人民法院判例)。 港澳台与国际判例即将推出。

如果我用了一段时间不想用了, 数据能导出吗? ▼

所有 Wiki 页和原始资料支持一键导出 Markdown / PDF / Word。 您的数据始终属于您, 取消订阅后保留 90 天可下载期。
