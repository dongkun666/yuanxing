示例代码

判例检索 - Python 
import lexprime

client = lexprime.Client(api_key="your_api_key")

results = client.cases.search(
    query="借款合同纠纷",
    court="北京市第一中级人民法院",
    page=1,
    size=10
)

for case in results.items:
    print(case.case_name, case.lex_score)
合同审查 - JavaScript 
const LexPrime = require('lexprime');

const client = new LexPrime({ apiKey: 'your_api_key' });

async function reviewContract() {
    const result = await client.contractReview.analyze({
        contractText: contractContent,
        contractType: 'loan',
        riskLevel: 'standard'
    });

    console.log('风险等级:', result.riskLevel);
    console.log('风险条款:', result.risks);
}
