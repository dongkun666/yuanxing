## 0. 文档使用说明 (W21 agent-candidates-w21, 10/1-10/15)

> **本文档是 3 agent 招聘的"简历筛选框架 + 30 简历筛选表 + 5 维度评分 + 3 轮淘汰流程"**.
> **执行团队**: BD (简历初筛 + 5 维度评分) + 现役 agent (复筛 + 面试) + Mavis owner (终面 + 录用决策) 3 线协作.
> **30 简历分配**: UI 设计师 10 份 + 前端工程师 10 份 + 数据工程师 10 份 = 30 份 (按 § 1 4 渠道 + 5 律师画像分布).
> **3 轮淘汰流程**:
> - 第 1 轮 (10/8-10/12): BD 初筛, 5 维度评分 ≥ 3.5 + 简历完整度 → 18 名入面试池 (各 6 名)
> - 第 2 轮 (10/13): 现役 agent 复筛, 5 维度评分 ≥ 3.8 + 文化匹配 ≥ 4.0 → 9 名入终面 (各 3 名)
> - 第 3 轮 (10/14-10/15): Mavis owner 终面, 5 维度评分 ≥ 4.2 + 加权 ≥ 4.5 → 3 名录用 + 3 名候补
> **关键时间表**: 详见 `agent-jd-w21.md` § 2.2 (10/1 D-Day → 10/15 24:00 简历截止 → 10/15 21:00 录用决策).

## 2. 5 维度评分细则 (3 agent 角色专项)

### 2.1 评分模板 (复用 W15 recruit-1000 + W10 B2 founding-member)

> **评分维度**: 0-5 分 (5 = 优秀, 4 = 良好, 3 = 合格, 2 = 待提升, 1 = 不合格, 0 = 严重不符)
> **加权得分公式**: `加权得分 = Σ(维度评分 × 维度权重)`
> **录用线**: 加权得分 ≥ 3.8 入面试池, ≥ 4.2 入终面, ≥ 4.5 推荐录用
