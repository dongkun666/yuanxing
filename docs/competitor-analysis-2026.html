战略卡位：自建 vs 免费接入 vs 不做
4 象限定位

决策变更后，4 象限比例倒置：从「20% 自建 + 60% API + 20% 不做」变为「80% 自建 + 15% 免费接入 + 5% 不做」。工程量翻 3-5 倍，但长期资产价值 10 倍提升。

我们已经做对的事（15 项）

  • 工作台 + 日程 + 案件 9 tab + 客户 + 模板 — 律所核心工作流覆盖完整
  • 知识库 LLM Wiki — 法律行业没人做（北大法宝是数据库, 我们是知识图谱）
  • 司法观点库 (12 条) — 借鉴《最高法司法观点集成》10828 条, 律师可直接引用
  • AI 文书生成（流式 6 类） + 法律期限 + 失信查询 + 案件进度 — 独家差异化
  • "AI 辅助、不替代律师" — 产品原则, 区别于智律云 Auto Pilot "替代人工"
  • IIFE 拆分 (script.js 53KB→18KB 首屏) — 性能基线为自建重平台铺路

绝对不做的（6 类）

  • 不做 C 端法律咨询（法行宝/法信小程序/法律百宝箱/叮咚律助）
  • 不做 to 律所管理（Clio 是全球第一, 我们 to 律师 + 律所版）
  • 不接收费 API（启信宝/天眼查/北大法宝/聚法/小包公/e签宝/飞书妙计）— 决策变更
  • 不自建 OCR 大模型（用 PaddleOCR/Whisper 开源）+ 法律微调
  • 不做案源抓取（合规风险）
  • 不自训基础大模型（自部署 Qwen/DeepSeek + 法律微调, 训练 = 烧钱）

免费接入（4 项 · 公开数据）

  • 国家法律法规数据库（国务院免费 API, 法规主源）
  • 人民法院案例库（最高法 2024 重启, 指导性案例 + 典型案例）
  • 中国执行信息公开网（公开查询, 跳转为主 + 律师证登录）
  • 国家企业信用信息公示系统（工商原始数据, 补充启信宝自建）

必须自建的（11 项）

  • 判例库：人民法院案例库 + 裁判文书网爬取 + 律师自加
  • 法规库：国家库为主 + 自建司法解释/指导案例/复函
  • 企业征信库：国家企业信用 + 启信宝/天眼查公开数据爬取
  • 失信被执行：跳转官网 + 自建缓存
  • OCR：PaddleOCR + 法律垂类微调
  • 语音转写：Whisper-large-v3 + 中文法律微调
  • 电子签：CFCA + 区块链存证 + 司法链对接
  • 大模型：自部署 Qwen2.5-72B / DeepSeek-V3 + 法律微调
  • 模板库：律所自维护 + 公开模板聚合
  • 司法观点库（已做）：律师自加 + 内部批注
  • LLM Wiki（已做）：知识图谱, 持续自维护
关键判断：LexPrime 的护城河不是"接了什么 API", 而是"自建的判例 + 模板 + 征信 + OCR + 转写 + 电子签 + LLM"这 7 大资产库。律师离开 LexPrime 损失所有历史数据和微调过的模型 — 这是 Clio/Alpha/智律云都没有的、用钱买不到的壁垒。

自建路径详细方案（7 大资产库）
技术栈 + 数据源 + 时间表

11 项自建, 实际是 7 大资产库。每个库的技术栈 / 数据源 / 工期 / 风险如下。

1. 判例库

1.2 亿+ 公开裁判文书

数据源：人民法院案例库（每日增量） + 中国裁判文书网（公开爬）
存储：PostgreSQL + 全文检索（Elasticsearch / Meilisearch）
爬虫：分布式（10 节点）+ 代理池 + 慢速 1 req/s + 随机 UA
合规：脱敏（删身份证/手机/详细住址）+ 来源标注 + 不存储未公开判决理由
工期: 6-8 周 · 节点: 20 个爬虫节点 · 风险: 中
2. 法规库

国家库 + 司法解释 + 复函

数据源：国家法律法规数据库 API（主源, 免费）+ 司法解释 + 复函（爬最高检/最高法）
存储：PostgreSQL + 版本控制（修订历史）
AI 增强：LLM 提取关联法条 + 自动识别修订关系
差异化：比国家库多 "案例关联" + "司法解释" + "复函"
工期: 3-4 周 · 节点: 2 个爬虫 · 风险: 低
3. 企业征信库

500 万+ 主要企业

数据源：国家企业信用信息公示系统 API（主源）+ 启信宝/天眼查公开页面
存储：PostgreSQL + 图数据库（Neo4j）股权穿透
爬虫：只爬公开页面（不绕过登录/付费墙）+ 5 节点分布式
合规：加密存储 + 律所隔离 + 标注来源 + 不存个人手机号/身份证
工期: 4-6 周 · 节点: 5 个爬虫 · 风险: 中
4. OCR 引擎

PaddleOCR + 法律微调

技术栈：PaddleOCR（百度开源, 准确率 95%+） + 法律垂类微调
微调数据：10 万+ 扫描件样本（律师上传 + 公开判决书扫描件）
场景：判决书 / 合同 / 律师函 / 证据材料 OCR 转可编辑文本
部署：GPU 服务器自部署（也可 PaddleOCR 推理 API 模式）
工期: 4-6 周（含微调） · GPU: 1xA100 · 风险: 中
5. 语音转写

Whisper + 中文法律微调

技术栈：Whisper-large-v3（OpenAI 开源, 中文 95% 准确率）+ 中文法律微调
微调数据：1 万+ 庭审录音片段（律师上传）
场景：庭审录音 + 客户会谈 + 律师笔记录音转文字
部署：GPU 服务器自部署
工期: 4-6 周 · GPU: 1xA100 · 风险: 中
6. 电子签

v1 自建 + v2 CA 认证

v1 阶段：律师自签（律师证 + 邮箱确认）+ PDF 存档 + 哈希存证
v2 阶段：接 CFCA / 国密 SM2 证书 + 区块链存证 + 司法链对接
牌照：电子认证服务许可证（工信部审批, 6-12 月不现实）
差异化：区块链 + 司法链对接（v2）, 让签的合同"打官司能直接当证据"
工期: v1 3 周 · v2 12 周 · 风险: v1 低 / v2 高
7. LLM 大模型

Qwen2.5-72B + 法律微调

基座：Qwen2.5-72B-Instruct（阿里开源, 推理能力强）或 DeepSeek-V3
微调：LoRA + 法律垂类数据（10 万+ 法律问答 + 判决书 + 合同 + 法规）
部署：GPU 集群（4-8 x A100/H100）+ vLLM 推理框架
能力：法律问答 / 文书生成 / 合同审查 / 案情分析 / 法规检索
工期: 8-12 周 · GPU: 4-8xA100 · 投资: ¥1-3M · 风险: 高
13
风险评估（8 大风险）
高 / 中 / 低 三档

自建战略最大风险不是技术, 是合规 + 维护成本 + 时间。下面 8 大风险按等级分类, 每条都给出 mitigation。

反爬与封禁 高

裁判文书网 / 启信宝 / 天眼查都有反爬（IP 封禁 / 验证码 / 行为分析）。单 IP 爬取 1 万次/天就触发, 严重时账号封禁。

→ 分布式 10-20 节点 + 代理池 + 慢速 1 req/s + 模拟真实用户行为 (随机滚动/停留) + 备用域名/IP 池

数据合规边界 高

爬取公开数据需谨慎: 个人信息（手机/身份证/详细住址）合规风险, 未公开判决理由爬取违法。爬到不存是底线, 存了 = 风险。

→ 只爬公开页面 + 自动脱敏 (正则替换) + 标注来源 + 律所数据隔离 + 不存储敏感字段

GPU 集群投资 高

自部署 Qwen2.5-72B 需要 4-8 张 A100, 硬件投入 ¥1-3M, 加上运维 (电费/冷却) 每月 ¥3-5 万。LLM 微调需要法律垂类数据 (10 万+ 样本), 数据获取难。

→ 先用 1-2 张 A100 跑 Qwen2.5-7B (开源小模型) 验证 PMF, 商业化后再扩到 72B

数据维护与时效 高

裁判文书每日新增 5,000+, 法规每月修订 50+ 条, 企业变更随时发生。自建数据库需要 7x24 增量更新, 工程量大。

→ 增量爬虫 (每日凌晨 1 次) + 失败重试 + 数据校验 + 律师自加 (用户也是数据源)

OCR/转写准确率 中

法律文书用词专业, 通用 OCR (PaddleOCR/Whisper) 在专业术语 / 表格 / 公式场景准确率可能掉到 80% 以下, 律师不敢直接用。

→ 法律垂类微调 (10 万+ 样本) + 人工校对界面 + 不追求 100% 准确, 80% 转写 + 人工校对 5 分钟可接受

技术债务 中

自建 7 大库 + 自部署 LLM = 复杂技术栈 (Python + Go + Rust + JS + DB + ES + GPU), 团队需要 3-5 个全栈 + 1-2 个 ML 工程师, 当前团队规模可能不够。

→ 优先做 1-2 个核心库 (判例库 + LLM), 其他库用 mock/跳转占位, PMF 验证后再扩

电子签牌照 中

完整电子签需要电子认证服务许可证 (工信部审批), 自建 6-12 月不现实。短期 LexPrime 只能做"律师自签 + 邮件确认 + 哈希存证"占位。

→ v1 阶段用 PDF + 哈希 + 邮件确认占位, v2 阶段接 CFCA 证书 + 区块链 + 司法链

免费数据源稳定性 低

国家库 API / 人民法院案例库 / 国家企业信用系统可能改版或限流。

→ 多个数据源交叉验证 + 缓存层 + 优雅降级（API 挂了, 跳转到官方）
