## 0. 执行摘要 (TL;DR)


**LexPrime** 是面向**中国律师**的全流程法律 Agent 平台, 通过桌面端 SaaS 形态覆盖律师办案全生命周期——从接案到结案, 从文书生成到庭审准备, 从类案参考到个人知识沉淀。

> **"数据完全由你掌控, 智能真正为你所用。"**

- **不是** 替代律师的 AI 律师
- **而是** 律师的 AI 超级分析师 / 策略参谋 / 知识管家
- **核心用户**: 独立律师 / 小型团队 (个人版) + 中大所 / 公司法务部 / 政府法务 (企业版)
- **核心价值**: 5 大核心步骤 + 1 立案预审 + 9 横切面模块 + 个人知识库 + 类案大数据 + 自适应引擎 + 深度护城河
- **第一性原则**: **数据完全本地化, 智能但非替代, 越用越懂你, 立案前智能预审, 类案数据只做参考**
- **数据原则**: 0 收费 API, 100% 自建数据 (4 公开源 + cncases 8500 万判例 + Qwen2.5-72B)
- **商业模式**: 个人版 ¥99/月 或 ¥799/年, 企业版 ¥1500-2000/律师/年, 30 天全功能免费试用

## 1. 产品定位


### 1.1 一句话定位

**LexPrime = 律师的全流程法律 Agent 框架, 而不是 AI 律师。**

我们明确划清边界:

| LexPrime 做 | LexPrime **不**做 |
|---|---|
| 全流程案牍工作自动化 (接案 / 立案 / 文书 / 庭审 / 结案) | 给当事人提供法律意见 |
| 律师专业工作的 AI 辅助 (类案检索 / 法规速查 / 庭审剧本) | 替代律师出庭 |
| 个人版 + 企业版 律所内部协作 (案件 / 客户 / 日程 / 归档 / 模板) | 律师 ↔ 客户的撮合交易 |
| 律师 ↔ 客户 沟通的内容生产 (起诉状 / 答辩状 / 律师函) | 律师执业证替代 |
| **本地知识沉淀** (律师个人风格 / 历史经验) | 自动上传数据到云端 |
| **类案大数据参考** (支持率区间 / 判赔金额分布, 严格中立) | "胜诉率" 预测 / 案件结果预测 |

### 1.2 战略原则 (第一性原则)

> **"数据完全由你掌控, 智能真正为你所用。"** —— 这是 LexPrime 的**第一性原则**, 所有产品决策围绕此原则。

**5 大核心价值主张**:

1. **数据完全本地化** —— 所有办案数据和知识库均存储在律师自己的电脑上, **绝不上传云端**。AI 在本地运行, 无隐私泄露风险。
2. **智能但非替代** —— AI 负责归纳整理、草拟文书、检索类案、提醒风险, **但所有最终决策必须由律师做出**。
3. **越用越懂你** —— 系统学习每位律师的文书风格、策略偏好和工作习惯, **逐渐成为专属的智能助手**。
4. **立案前智能预审** —— 提前按法院 / 仲裁委标准检查材料完整性与规范性, **显著降低立案被退回概率**。
5. **类案数据只做参考** —— 提供类案支持率区间、判赔金额分布等统计数据, **绝不做"胜诉率"预测, 界面用语严格中立**。

理由:
- **法律风险**: 律师对当事人承担专业责任, AI 不能分担律师执业证
- **合规要求**: 中国《律师法》明确 AI 不能替代律师执业, 不能给当事人提供法律意见
- **数据安全**: 律师案件数据高度敏感 (当事人隐私 / 商业秘密), 本地化是硬约束
- **用户信任**: 律师对工具的信任度, 取决于"我说了算还是 AI 说了算"
- **市场定位**: AI 律师赛道有"法行宝"等大厂在做, LexPrime 不与之为敌, 做律师的左膀右臂

## 2. 市场背景


### 2.1 中国律师行业现状

| 指标 | 数据 | 来源 |
|---|---|---|
| 中国执业律师总数 | ~70 万 | 司法部 2024 |
| 中小所 (≤10 人) 占比 | ~95% | 中华全国律协 |
| 单飞律师 (无团队) | ~30% | 行业调研 |
| 平均日案牍时间 | 4-6 小时 | 用户访谈 |
| 数字化工具渗透 | < 30% | 行业报告 |
| 案源获取成本 | 30-50% 收入 | 律协调研 |

### 2.2 痛点 (按严重度排序)

1. **案牍工作吞噬时间** — 平均 60-70% 工作时间在写文书 / 整证据 / 跑流程
2. **法规更新快, 检索成本高** — 新法规 / 司法解释 / 指导案例持续涌现, 律师靠经验记忆跟不上
3. **类案检索效率低** — 中国裁判文书网访问慢, 检索结果质量参差
4. **立案材料反复被退回** — 法院立案标准繁琐, 律师最常见的挫败场景
5. **客户沟通成本高** — 同一个问题律师要给客户解释 3-5 次
6. **律所管理工具落后** — Excel + 微信群, 协同混乱
7. **案源不稳** — 律师业务波动大, 需要稳定案源
8. **数据安全担忧** — 上传第三方平台处理, 客户数据泄露风险

### 2.3 竞品分析

| 竞品 | 定位 | 优势 | 劣势 | LexPrime 差异 |
|---|---|---|---|---|
| **元典智库** | 法律检索 + 类案 | 裁判文书数据全 | 案牍工具弱, 不做律师工作流 | LexPrime 做工作流, 不做检索平台 |
| **Alpha 智能** | 律师工具集 | 工具全 | 收费高 (¥500+/月), 中小所难以负担 | LexPrime ¥99 起, 走平民化路线 |
| **法行宝** | AI 律师 (ToC) | 大厂流量 | 不专业, 律师不用 | 不做 ToC 律师替代 |
| **律呗 / 法狗狗** | 律所管理 | 单一功能 | 功能浅, 无 AI | LexPrime 是 AI + 工作流一体化 |
| **北大法宝** | 法规数据库 | 法规权威 | 检索 UI 老, 案牍工具弱 | LexPrime 现代化 + 工作流 |
| **ChatGPT + 律师自建** | 通用 AI + 个人 | 灵活 | 数据上传, 不专业, 无工作流 | LexPrime 专业 + 本地 + 工作流 |

### 2.4 LexPrime 切入角度

**不做"AI 律师", 做"律师的全流程 AI 助理 + 本地化 + 数据主权"** —— 这个赛道目前没有强势玩家。
