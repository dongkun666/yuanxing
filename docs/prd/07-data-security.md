## 8. 数据安全策略 (本地优先)


> **第一性原则: 数据完全本地化, 智能但非替代。**

### 8.1 个人版

- **所有数据存储本地**, 绝不上传云端
- **AI 推理尽量本地执行** (可调用本地模型或脱敏后的 API 请求)
- 仅当用户**主动使用云端增强功能** (如复杂 OCR / 类案检索) 时, 才加密传输必要数据
- 云端数据处理完后**立即删除**

### 8.2 企业版

- **支持全私有化部署**, 数据永不上云
- 可选用混合云模式, 但敏感数据保留在内网
- **暗水印 / 审计日志 / 动态脱敏 / UEBA** 贯穿所有版本

### 8.3 深度护城河系统

- **不可迁移的第二大脑**: 所有知识关联、图谱、索引无法通过静态文件导出带走
- **内部黄金标准库**: 历史胜诉文书自动比对, 提示当前文书与最优版本的差异
- **合规驾驶舱 (企业版)**: 自动生成执业合规报告、风控健康度月报, 应对司法行政检查
- **全链路安全防护**:
  - **数据加密**: 敏感数据落盘 AES-256-GCM 加密, 传输 TLS 1.3
  - **动态脱敏**: 基于角色的动态数据脱敏
  - **暗水印注入**: 所有导出文档嵌入不可见数字水印
  - **操作审计**: 全链路操作日志不可篡改
  - **审批网关**: 按风险等级执行不同确认策略 (低 / 中 / 高 / 关键)
  - **UEBA 异常检测** (企业版): 学习正常用户行为, 检测异常操作
  - **软件二次验证**: 手机验证码 / TOTP (企业版可集成硬件密钥)
  - **全私有化部署**: 企业版支持完全本地部署, 数据永不上云
