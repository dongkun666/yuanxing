# Track J: 个人知识库 (LanceDB + 语义检索)

> 来源: PRD § 9.2 Phase 4 计划 · 12 周 Phase 4 第 11-14 (溢出) 周
> 负责人: 全栈 + AI · 优先级: P2 · 工时: 4 周

---

## 1. 目标

律师可沉淀个人知识 (历史案件 / 文书 / 策略), AI 优先参考本地知识库生成。

## 2. 范围 (In Scope)

- LanceDB 本地存储
- 语义检索 (律师历史经验)
- AI 优先参考 (生成文书时)
- 跨案件关联 (新案自动关联历史)
- 完全自愿沉淀 (不强制)
- 导出 / 删除权

## 3. 不在范围 (Out of Scope)

- 团队共享知识库 (企业版 Phase 5)
- 知识图谱深度关联 (Phase 5)

## 4. 任务分解

- W11: LanceDB 部署 + 存储 schema
- W12: 语义检索 + 知识沉淀 UI
- W13: AI 优先参考 + 跨案件关联
- W14: 导出 / 删除 + 律师反馈

## 5. 验收标准 (Acceptance Criteria)

- [ ] 律师可手动标记沉淀
- [ ] 语义检索准确率 ≥ 80%
- [ ] AI 生成时优先参考本地知识库
- [ ] 新案自动关联历史经验
- [ ] 一键导出 (Markdown + JSON)
- [ ] 一键彻底删除 (无残留)

## 6. 依赖

**前置 Track**: A (Auth) + E (Skill, 部分复用)
**技术依赖**: LanceDB / Embedding (BGE / M3E) / Qwen2.5-7B
**资源依赖**: 律师测试 (3-5 家)

## 7. 风险

- 知识库累积慢 → 激励机制 (产品引导)
- AI 过度依赖本地数据 → 本地 + 通用平衡
- 数据迁移成本 → 开放格式导出
