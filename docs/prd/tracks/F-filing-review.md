# Track F: 立案预审 3.5 步 (LexPrime 差异化亮点)

> 来源: PRD § 9.2 Phase 4 计划 · 12 周 Phase 4 第 9-12 周
> 负责人: 全栈 · 优先级: P1 · 工时: 4 周

---

## 1. 目标

律师在立案前可一键预审, 系统按法院 / 仲裁委标准检查材料完整性与规范性, 降低立案被退回概率。

## 2. 范围 (In Scope)

- 法院 / 仲裁委立案标准库 (覆盖 100+ 法院)
- 材料完整性自动检查
- 格式规范性自动校验
- 预审报告 (红黄绿灯)
- 一键补全缺失文书
- 管辖校验

## 3. 不在范围 (Out of Scope)

- 各地仲裁委 (Phase 4.5)
- 律师社区反馈 (Phase 4.5)
- 立案经验库 (Phase 5)

## 4. 任务分解

- W9: 立案标准库 schema + 100+ 法院数据采集
- W10: 完整性检查 + 格式校验 + 管辖校验
- W11: 预审报告 UI + 红黄绿灯
- W12: 一键补全 + 律师社区反馈通道

## 5. 验收标准 (Acceptance Criteria)

- [ ] 100+ 法院立案标准库可查
- [ ] 预审报告 5 秒内生成
- [ ] 红黄绿灯标识准确 (律师抽样验证 ≥ 90%)
- [ ] 一键补全 8 大类文书
- [ ] 管辖校验: 标的额 + 被告住所地自动判断

## 6. 依赖

**前置 Track**: A (Auth)
**技术依赖**: 法院数据采集 (爬虫 + 人工审核) / 规则引擎 (JSON Schema)
**资源依赖**: 律师顾问验证 (5 家律所抽样)

## 7. 风险

- 法院标准更新快 → 律师反馈通道 + 持续维护
- 地方差异大 → 按地域分级 (北上广深优先)
- 仲裁委规则复杂 → Phase 4.5 单独做
