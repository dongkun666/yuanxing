# Track H: 文书智能增强 (校对/排版)

> 来源: PRD § 9.2 Phase 4 计划 · 12 周 Phase 4 第 11-12 周
> 负责人: 全栈 · 优先级: P1 · 工时: 2 周

---

## 1. 目标

律师生成或上传文书后, 系统自动校对 (错别字 / 法律术语 / 金额日期一致性) + 一键排版。

## 2. 范围 (In Scope)

- 错别字检查 (通用 + 法律术语)
- 金额日期一致性校验
- 当事人名称一致性
- 各级法院格式模板
- 一键排版套用

## 3. 不在范围 (Out of Scope)

- 律所自定义排版标准 (企业版 Phase 5)
- 法律文书生成 (Phase 4 已有 AI 文书)

## 4. 任务分解

- W11: 校对引擎 (错别字 + 法律术语 + 一致性)
- W12: 排版模板 (10+ 法院) + 一键套用

## 5. 验收标准 (Acceptance Criteria)

- [ ] 错别字检查准确率 ≥ 95%
- [ ] 法律术语误用识别 (定金/订金 等)
- [ ] 金额日期矛盾标红
- [ ] 10+ 法院排版模板可一键套用

## 6. 依赖

**前置 Track**: 无 (可独立)
**技术依赖**: NLP 校对 (HanLP) / 模板引擎 (Jinja2)
**资源依赖**: 法院格式模板 (10+ 法院采集)

## 7. 风险

- 法律术语库不全 → 律师反馈 + 持续扩充
- 排版标准差异大 → 按法院分级
