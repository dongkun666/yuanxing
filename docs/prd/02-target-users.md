### 3.1 版本策略

### 3.2 一号用户: 独立律师 / 单飞 (个人版主用户)

| 属性 | 描述 |
|---|---|
| 画像 | 30-50 岁, 执业 3-10 年, 无团队或 1-2 人助理 |
| 业务 | 民商事为主 (合同纠纷 / 婚姻家事 / 劳动 / 债权) |
| 案源 | 老客户回头 + 转介绍, 偶尔互联网获客 |
| 日均工作量 | 接案 2-3 件, 案牍 4-6 小时 |
| 工具现状 | Word + WPS + 微信 + Excel, 偶尔用 Alpha |
| 月可支配工具预算 | ¥200-500 |
| 痛点 | 时间全在案牍, 没时间做专业深耕; 类案检索靠裁判文书网, 慢 |

**典型一日**:
1. 早上 9:00 起床后微信回客户 5 条
2. 9:30-12:00 写昨天接的合同纠纷起诉状
3. 13:00-14:00 跑法院交材料
4. 14:00-17:00 整理证据卷宗, 写证据目录
5. 17:00-18:00 接客户电话 2 个
6. 晚上 19:00-22:00 写第二份律师函

**LexPrime 帮他省**: 起诉状 3h → 1h, 证据目录 2h → 30min, 律师函 2h → 30min
