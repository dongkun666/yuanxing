## 4. 核心场景 (5 大核心步骤 + 1 立案预审)


LexPrime 围绕律师办案**全生命周期**构建 **5 大核心步骤 + 1 立案预审步骤 + 9 横切面模块**。

### 4.1 第 1 步: 接案与客户资料创建 (P0)

**痛点**: 律师接到新案, 需要在 1-2 天内完成客户信息 / 案件信息 / 利益冲突 / 案件材料梳理。

**LexPrime 价值**:
- **智能文档预处理引擎**: PDF / Word / PPT / Excel / 图片 / 音频 / 视频 / 微信聊天记录, 全部转化为 Markdown 文本 + 结构化元数据
- **材料上传与 AI 自动解析**: 拖拽 / 批量 / 拍照 / 语音, 排队 / 处理 / 完成, 失败可重试
- **客户 / 案件信息自动提取**: 15 字段, AI 提取 + 手动补全双路径
- **利益冲突检索**: 实时模糊检索 (相似客户 / 曾用名), 多层穿透 (客户 / 对方 / 证人 / 关联方)
- **客户画像与隐性诉求挖掘**: AI 推断客户真实需求
- **案件材料库**: 增删改查 + 来源锚定 + 版本管理
- **案件复杂度预测**: 低 / 中 / 高, 推荐工作计划模板
- **信息冲突可视化解决**: 多材料不一致生成冲突卡片

### 4.2 第 2 步: 委托手续与案情初步分析 (P0)

**痛点**: 律师需要签委托合同 / 风险告知书 / 案情分析报告。

**LexPrime 价值**:
- **委托代理合同**: 模板填空, 条款自动组装, 代理费自动算
- **授权委托书**: 按代理阶段自动配置授权范围
- **风险告知书**: 客户画像驱动的千人千面呈现
- **模板管理系统**: 上传 / 占位符自动映射 / 版本管理 / 法律体检
- **案情摘要**: 当事人关系图 + 关键事实时间轴 + 争议焦点预判
- **诉讼策略分析**: 法律依据 + 类案摘要 + 初步策略建议 + 证据清单
- **智能费用计算器**: 多种收费方式 + 自动生成费用条款
- **签约前能力展示**: 脱敏版案件策略看板

### 4.3 第 3 步: 核心诉讼文书与程序性文书 (P0)

**痛点**: 律师要写起诉状 / 答辩状 / 证据目录 / 程序性申请书。

**LexPrime 价值**:
- **证据目录**: 自动排序 (主体资格 → 程序性 → 实体性 → 其他) + 证明目的 + 类案采信度 + 动态证明力评分
- **起诉状**: 自动填充 + 诉讼请求 AI 草拟 + 事实锚定证据 + 法条引用
- **答辩状**: 拆解对方主张 + 三种答辩立场 (否认 / 承认但抗辩 / 部分承认) + 应诉策略
- **上诉状**: 提取原审错误 + 上诉理由框架
- **证据册**: 自动匹配 / 重命名 / 合并 / 页码 / 水印 / 封面
- **证据链可视化**: 节点-连线图 + 薄弱节点高亮
- **程序性文书**: 财产保全 / 管辖权异议 / 证据保全 / 延期举证 / 追加当事人 / 不公开审理, 全部 AI 草拟
- **法律引用实时有效性检查**: 引用时检查法条是否现行有效

### 4.4 第 3.5 步: 立案材料智能预审 (P0, LexPrime 差异化亮点)

**痛点**: 律师立案材料被法院 / 仲裁委退回是最常见的挫败场景。

**LexPrime 价值**:
- **法院 / 仲裁委立案标准库**: 各级法院立案指南 + 各地仲裁委规则 + 律师社区反馈
- **材料完整性自动检查**: 起诉状份数 / 证据副本份数 / 授权委托书 / 身份证复印件
- **格式规范性自动校验**: 纸张 / 字体 / 页边距 / 落款
- **预审报告**: 红黄绿灯标识 + 已满足项 + 需补充项 + 建议优化项
- **一键补全**: 缺失文书可一键生成
- **管辖校验**: 自动根据标的额 / 被告住所地判断管辖权
- **动态更新**: 立案标准库持续更新, 律师可反馈实际立案经验

### 4.5 第 4 步: 庭审准备 (P0)

**痛点**: 律师出庭前要准备质证提纲 / 发问提纲 / 代理词。

**LexPrime 价值**:
- **质证提纲**: 四维度分析 (真实性 / 合法性 / 关联性 / 证明力) + AI 对抗模拟 + 法官视角风险提示
- **发问提纲**: 决策树结构 + 高风险标注 + 证人画像
- **代理词 / 辩护词**: 法官画像驱动 + 多策略选择 + 争议焦点预测
- **铁律**: 绝对禁止自认不利事实; 与证据目录、质证提纲保持逻辑闭环; 法条引用全文并检查时效

### 4.6 第 5 步: 案件流转与终结 (P0)

**痛点**: 律师接到判决后, 要管理执行 / 归档 / 知识沉淀。

**LexPrime 价值**:
- **判决结果管理**: AI 解析判决书 + 胜败诉分析 + 上诉期倒计时 (15/7/3/1 天) + 履行期监控
- **执行阶段管理**: 一键生成《申请执行书》 + 财产线索管理 + 执行时效预警 (2 年红线)
- **结案归档**: 卷宗目录自动生成 + 一键打包 + 故事线导出
- **个人知识沉淀**: 案件基因提取 + 策略复盘 + 败诉价值深挖 (完全自愿, 不强制)
