### 15.5 核心机制详解

**1. 上下文语义索引**:
- 材料段落向量化 (LanceDB / Milvus)
- AI 对话时检索最相关段落注入 Prompt
- Token 预算 ≤8000

**2. 统一工具注册中心**:
- 所有功能和 Skill 实现统一 Tool 接口
- AI 可动态发现和组合调用

**3. 自主办案循环**:
- 复杂任务 AI 生成计划步骤
- 逐步执行观察
- 关键决策点暂停确认
- FSM 状态管理

**4. 法务级修订审批流**:
- 文书基于操作序列 (OT) 存储
- 逐条接受 / 拒绝
- 企业版审批链

**5. 深度记忆**:
- **事实记忆**: 键值存储, 记住用户偏好和事实
- **风格记忆**: 向量化存储文书偏好
- **策略记忆**: 记录历史策略决策, 新案推荐
- 三层记忆系统注入每次 Prompt

**6. SOP 工作流引擎**:
- YAML 定义
- 自动推进, 联动日程任务
- 预置模板: 民事诉讼一审 / 劳动仲裁 / 合同审查 / 刑事辩护
- 企业版自定义 SOP
