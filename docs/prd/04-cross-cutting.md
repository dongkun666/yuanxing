## 5. 核心场景 (9 大横切面模块)


横切面模块不依赖具体案件阶段, 贯穿律师工作全流程。

### 5.1 横切面 1: 日程中心 (P0)

| 触发事件 | 自动生成日程 |
|---|---|
| 创建案件填写签约时间 | 签约日期 |
| 录入收到起诉状日期 | 答辩期届满 (+15 天) |
| 生成财产保全申请书 | 保全裁定跟进 (+3 天) |
| 录入开庭日期 | 庭前准备 (7/3/1 天提醒) + 庭后补充意见 (+5 天) |
| 上传判决书 | 上诉期届满 (+15 天) + 判决履行期 |
| 标记进入执行 | 执行立案跟进 (+7 天) + 执行时效届满 (+2 年) |
| 证据缺失提醒触发 | 证据补充待办 (截止举证期前 7 天) |

**核心功能**:
- **手动日程创建**: 快捷键 (Ctrl+Shift+N) / 语音输入, AI 解析时间 / 地点 / 人物 / 案件关联
- **多视图面板**: 今日 / 周月历 / 案件时间轴 (甘特图) / 列表
- **四级智能提醒**: 🔴 法定红线 (弹窗 + 短信 / 邮件 + 需确认关闭) / 🟡 重要节点 (弹窗 + 通知) / 🔵 工作安排 (通知) / 🟢 客户关怀 (侧边栏弱提醒)
- **智能感知**: 自动避开法定节假日和法院休庭日; 创建会见日程时自动计算路程时间
- **负载诊断** (企业版): 检测时间冲突和超负荷, 向管理者预警

### 5.2 横切面 2: 客户关系管理 CRM (P1)

- **客户 360 视图**: 基本信息 + 关系图谱 + 沟通日志 + 服务价值看板 (LTV 预估)
- **线索与机会管理**: 快速记录 + AI 自动分类 + 推荐擅长律师 + 一键转化
- **客户维护与洞察**: A/B/C 分级 + 个性化关怀 (节日 / 案件周年) + 案源渠道分析

### 5.3 横切面 3: 证据缺失提醒 (P1)

- **触发节点**: 接案后 / 生成证据目录时 / 撰写文书时 (实时侧边栏) / 庭前 7/3/1 天 / 收到对方证据清单后
- **提醒深度**: 缺失项 → 涉及待证事实 → 法律风险 (法条) → 类案数据 (败诉率) → 替代方案
- **证据健康度仪表盘**: 红黄绿灯 + 雷达图 + 详细诊断
- **证据抢救模式**: 举证期临近仍缺失, 自动打包生成《证据调查与补救方案》

### 5.4 横切面 4: 技能引擎 Skill Hub (P1)

**官方内置 9 个 Skill** (Phase 4 规划):

1. **类案检索与裁判参考** — 多维度检索 + 统计数据 + 用语中立
2. **法律研究备忘录** — 法条 / 类案 / 学术观点 + 结构化备忘录
3. **民间借贷纠纷分析** — 借条效力 + 合法利息 + 类案检索
4. **劳动争议仲裁辅助** — 赔偿金计算 + 仲裁申请书 + 证据清单
5. **离婚纠纷财产分割** — 共同财产梳理 + 分割方案
6. **合同风险审查** — 逐条审查 + 风险等级 + 修改建议 + 谈判策略 + 版本比对
7. **遗嘱合规检查** — 形式要件 + 见证人资格 + 必留份预警
8. **刑事辩护辅助** — 会见提纲 + 证据合法性审查 + 量刑参考
9. **法律知识问答** — RAG 问答

**技能包结构**: manifest.json (元数据 / 权限 / 依赖) + prompt.md + 知识库文件 + 工具定义

### 5.5 横切面 5: AI 对话 (统一自然语言接口) (P0)

- **上下文全感知**: 进入案件自动加载全案信息
- **意图识别**: 信息查询 / 知识分析 / 任务执行
- **多模态输入**: 文字 / 语音 / 文件 / 截图
- **输出即工具**: 结构化卡片 + 内嵌按钮 (预览 / 下载 / 编辑 / 审批)
- **多轮对话 + 对话分支**: 可回溯创建新分支
- **法律边界**: 拒绝违规指令 + 不替代律师 + 强制标注来源 + 免责声明
- **全局快捷键**: Ctrl+Space 呼出指令条
- **双模式标识**: 明确区分"基于本地数据"和"已联网检索"

### 5.6 横切面 6: 当事人服务类文书 (P1)

- **借条 / 欠条**: 要件完整性校验 + 合法利率预警 (LPR 四倍) + 自动生成
- **各类合同**: 生成模式 (立场识别 + 条款组装) / 审查模式 (逐条风险标注) / 版本比对
- **遗嘱**: 形式要件清单 + 见证人资格审核 + 必留份制度预警
- **上访材料**: 事实结构化 + 诉求提炼 + 管辖指引
- **律所办案文书**: 所函 / 介绍信 / 律师函 (策略性, 语气可选) / 会见介绍信

### 5.7 横切面 7: 类案判决大数据参考 (P1)

> **核心定位**: 从"搜索工具"升级为"大数据参考平台", **界面只呈现统计数据, 不做确定性判断**。

- **多维度检索**: 案由 + 关键事实模式 + 审理法院 + 审理法官 + 裁判年份
- **裁判数据统计**:
  - 支持率趋势 (柱状图, 近 5 年)
  - 判赔金额参考区间 (箱线图, 中位数 / 四分位距 / 极值)
  - 主要争议焦点分布
  - 法条引用频率
- **法官审理风格参考**: 审理数量 + 支持倾向 + 证据采信倾向 + 平均审理周期

**界面语言规范 (强制执行)**:
- ✅ 正确: "近 3 年本法院 87 件类似案件中, 支持原告诉请的 72 件 (约 83%)"
- ❌ 禁止: "本案胜诉率约 83%"
- ✅ 正确: "该法官在同类案件中, 判赔金额中位数约 XX 元"
- ❌ 禁止: "预计本案判赔 XX 元"
- 所有页面底部强制显示: "以上数据仅为已公开裁判文书的统计结果, 不代表对本案结果的任何预测或判断。"

### 5.8 横切面 8: 费用管理 (仅手动计时) (P2)

- **手动计时**: 开始 / 暂停 / 停止, 律师完全控制; 事后可编辑
- **批量录入**: 支持事后批量录入整块时间
- **费率与账单**: 按律师 / 案件类型 / 工作类型设置费率, 一键生成账单
- **企业版增强**: 审批流 + 经营分析 (收入趋势 / 律师贡献 / 案由收入 / 回款率)

### 5.9 横切面 9: 团队协作与任务管理 (企业版) (P1)

- **案件任务看板**: 列视图 (待办 / 进行中 / 已完成) + 拖拽 + 截止日 + 优先级 + 指派人
- **@ 提及与评论**: 在文书 / 证据 / 任务中可 @ 成员, 讨论留存时间线
- **工作量看板**: 成员负载图表 + 超荷预警 + 重新分配
- **模板化任务清单**: 按案由预设标准任务清单, 新建案件一键生成
