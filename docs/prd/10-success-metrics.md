## 11. 成功指标


### 11.1 北极星指标

**WAU (Weekly Active Users) / 付费用户数** —— 律师的周活, 反映工具粘性.

### 11.2 Phase 4 关键指标 (3 个月)

| 指标 | 目标 |
|---|---|
| 注册律师数 | 500+ |
| 30 天试用 → 付费转化率 | 30%+ |
| MAU 留存 (30 日) | 60%+ |
| 日均使用时长 | 1+ 小时 |
| NPS (净推荐值) | 40+ |
| ARR (年化经常性收入) | ¥20 万+ |

### 11.3 长期指标 (12 个月)

| 指标 | 目标 |
|---|---|
| 付费律师 | 500+ |
| ARR | ¥100 万+ |
| 企业版客户 | 5+ |
| 企业版 ARR | ¥30 万+ |
| 总 ARR | ¥130 万+ |

### 11.4 防御性指标

- **日活 / 月活 (DAU/MAU)**: > 40% (工具类高粘性)
- **7 日留存**: > 70% (律师工具一旦用上不易离开)
- **功能使用广度**: 平均用户使用 > 5 个 view / 周
