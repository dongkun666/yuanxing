### 10.2 企业版 (Phase 5 后)

| 维度 | 个人版 | 企业版 |
|---|---|---|
| 核心用户 | 独立律师 / 小型团队 ≤5人 | 中大型律所 / 公司法律部 / 政府法务 |
| AI 能力 | 全功能不限次数 | 全功能 + 团队协作 + 知识共享 |
| 技能引擎 | 所有官方技能 | + 自定义技能 + 权限分配 |
| 费用管理 | 手动计时 + 账单 | + 审批流 + 经营分析 |
| 团队协作 | 不支持 | 任务看板 + @ 提及 + 工作量管理 |
| 行业洞察 | 不支持 | 地域热力图 / 蓝海分析 / 对标 / 驾驶舱 / 报告 |
| 本地知识库 | 完全本地, 完全私有 | 支持本地或团队共享库 |
| 安全等级 | 本地加密 + 基础权限 | 全链路审计 + 动态脱敏 + 私有化部署 + UEBA |
| **定价** | **¥99/月 或 ¥799/年** | **¥1500-2000/律师/年** |
| 试用 | 30 天全功能 | 30 天 + 专属顾问 |

### 10.3 推广策略

- **个人版 30 天全功能免费试用**
- **"创始体验官" 计划**: 邀请 100 位资深律师免费使用 1 年专业版
- **内容营销**: 产品自身生成类案大数据报告、诉讼策略白皮书在律师社群传播
- **案件协作自然裂变**: 一个律师使用, 邀请团队协作时带来新用户
- **冷启动**: 3 个种子律师 (产品经理个人律师朋友) → 7 天免费试用 → 5-7 折首年 → 30% 转化

### 10.4 增长目标

- **6 个月**: 100 个付费律师, ARR ¥20 万
- **12 个月**: 500 个付费律师, ARR ¥100 万
- **18 个月**: 5 个企业版客户, 总 ARR ¥130 万
