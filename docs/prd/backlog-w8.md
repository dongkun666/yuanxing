### 2.1 新需求 #1: UI 团队协同 (主任派单+授薪审查+主任审核+任务分配+进度看板+风险汇总+主任一键审核)

#### 2.1.1 需求描述

**核心痛点** (评审 #1 L2 评审 #2 L4 共同反馈):
- 主任 (L2 小所合伙人 / L4 中所合伙人) 1 周有 10-15h 在审核授薪律师的合同, 急需团队协同 UI
- 当前 Skill 2 是单用户版, 不支持主任派单 + 授薪审查 + 主任审核
- L4 中所: 1 周有 5-8h 在审合同, 急需风险驾驶舱 (本月 50+ 合同, 致命/重大风险 Top 10)

**功能需求**:
1. **任务分配** (主任派单给授薪律师, 授薪律师接收任务 + 审查 + 提交)
2. **进度看板** (谁审了什么, 进度如何, 任务状态: 待派单 / 审查中 / 待审核 / 已审核 / 已驳回)
3. **风险汇总** (本月 50+ 合同, 致命/重大风险 Top 10 + 共同让步空间 Top 5 + 共同红线 Top 3)
4. **主任一键审核** (授薪审查后, 主任直接看到致命条款, 一键 approve / reject + 批注)
5. **团队成员管理** (主任添加/移除授薪律师, 角色: 主任 / 主办律师 / 助理, 权限: 派单 / 审查 / 审核 / 查看)

### 2.2 新需求 #2: UI 客户友好版 (隐藏法条+突出风险+客户白话解释+律师一键切换)

#### 2.2.1 需求描述

**核心痛点** (评审 #1 L3 评审 #2 L5 共同反馈):
- 客户 (普通市民, 非律师) 完全看不懂当前 UI
- 当前 UI 是律师专用, 法条引用 + 修改建议都是律师语言
- 婚姻家事客户情绪化多, 看到"fatal 风险" 标签会非常紧张, 律师需花 10-15 min 解释
- L3 婚姻家事律师 50%+ 案件涉及情绪化客户, 急需客户版

**功能需求**:
1. **隐藏法条** (客户版默认隐藏法条引用, 律师版显示)
2. **突出风险** (用图标 + 大字号 + 颜色 代替文字 fatal/major/advisory/ok)
3. **客户白话解释** (每条风险加"客户白话解释" 字段, 例: "fatal = 这条对你很不利, 建议必须改")
4. **律师一键切换** (律师可在律师版/客户版之间一键切换, 不需要重新生成审查报告)
5. **情绪化客户适配** (UI 配色温和, 避免红色大字体, 改用橙色 + 图标)

#### 2.2.2 律师原始语言 (评审 #1 L3)

> **评审 #1 L3 §3.5 Q23 回答** (评审 #1 L3 试审 5 合同后, 总指挥 Q&A 15 min):
> "客户完全看不懂当前 UI. 当前 UI 是律师专用, 法条引用 + 修改建议都是律师语言, 客户 (普通市民) 看不懂, 反而会增加焦虑. 婚姻家事客户情绪化多, 看到'fatal 风险' 标签会非常紧张, 律师需要花 10-15 min 解释. 急需'客户友好版' UI:
> (1) 隐藏法条
> (2) 突出风险 (用图标代替文字 fatal/major)
> (3) 加'客户白话解释' (例如'fatal = 这条对你很不利, 建议必须改')
> (4) 律师一键切换律师版/客户版
> 这是 P0 改进, 婚姻家事场景必备."

> **评审 #2 L5 §3.5 Q20 验证** (评审 #2 L5 演示 W7 客户版):
> "Skill 2 合规风险表述 (法条引用 + 风险等级) 能直接转发给业务部门, 业务部门接受度 90% (我们公司业务部门尊重法务意见). 表述风格 OK: 严格中立 + 法条准确 + 风险等级清晰. 业务部门反馈: (1) 接受 AI 风险提示 (90%) (2) 接受法条引用 (95%) (3) 接受风险等级 (90%). W7 P0 改进 ('建议争取' 改'建议明确约定', 评审 #1 L3 提) 验证: 业务部门不再误解 AI 输出, 表述更准确."

> **评审 #2 L5 §3.5 Q25 验证** (评审 #2 L5 演示 W7 客户版 UI):
> "4 项配置全部必备 (按重要性排序): (1) 审计日志 (P0, 合规审计要求, 谁审了 + 时间 + 版本 + IP 地址) (2) SSO 集成 (P0, 公司账号登录, 接 LDAP/Active Directory) (3) 数据导出格式 (P0, Excel/PDF/Word + 公司模板) (4) 公司 Logo + 主题色定制 (P1, 品牌一致, 但非合规要求). 我们公司额外要求: (5) 数据本地化部署 (服务器在公司内网, 不上云) (6) **跨部门权限管理 (业务部门只读, 法务部读写)** (7) 私有模型微调 (公司行业条款 + 历史合同). **W7 私有化部署说明 PDF (07-22 总指挥准备) 验证: 4 项必备全部覆盖, 3 项我们公司额外要求作为 P1 扩展.**"
