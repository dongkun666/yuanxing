**业务量梯度验证**:
- L1 (5-10) → L2/L3 (10-30) → L4 (30-100) → L5 (100+), 跨度 4-5 倍递增, 覆盖小到大量审查场景

**立场视角覆盖**:
- 甲方视角: L1 (借款人/个人) + L4 (设备买方/企业)

- 审查方视角: L5 (企业法务/中立审查)

**业务类型覆盖**:
- 民商: L1 + L2 (合同纠纷为主)
- 婚姻家事: L3 (专属)
- 刑事: L1 (附带)
- 金融/商事: L4 (专属)
- 合同/合规: L5 (专属)
