## 五、寻找渠道 (供总指挥参考)

| 渠道 | 适用类型 | 实操方式 | 转化率 |
|---|---|---|---|
| **个人律师朋友** | 全部 | 直接约, 朋友网络优先 | 高 (80%+) |
| **朋友的朋友 (二跳)** | 全部 | 朋友引荐 + 总指挥约 | 中 (50%) |
| **校友网络 (法学校友)** | 全部 | 法学院/法硕同学群 | 中 (40%) |
| **地方律协沙龙** | 律所 | 参加沙龙 + 现场约 | 中 (30%) |
| **法律科技大会** | 律所 + 公司法务 | 参展/演讲/展台 | 中 (30%) |
| **专业律师社群** (智合/无讼/...) | 律所 | 写文章 + 主动联系 | 低 (20%) |
| **企业法务协会** (ACLA/FCAA) | 公司法务 | 参加活动 + 私域运营 | 中 (30%) |
| **创投圈法律人脉** (孵化器法务) | 公司法务 | 创投活动 + 1v1 | 中 (40%) |

> **建议配比**: 朋友网络 5 家 (种子) + 校友/朋友引荐 3 家 + 活动认识 2 家

## 八、风险与应对 (§7 Track C 风险)

| 风险 | 应对 |
|---|---|
| 律师时间难约 | 提前 2 周约, 灵活时间 (午餐/晚上/周末) |
