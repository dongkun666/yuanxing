# 律师访谈大纲 v0.1

> **用途**: 创始人 (总指挥) 线下 1-2h 深度访谈使用
> **覆盖**: 4 类用户 (单飞/小所/中大所/公司法务)
> **目标**: 痛点排序 + 工具现状 + 预算意愿 + 内测转化
> **配套文件**: `target-list.md` · `interview-NN-<name>.md`

---

## 0. 开场白 (3 分钟)

> 您好,我是 LexPrime (元枢法智) 的产品负责人, 我们正在为律师做一款本地化 AI 助手。
> 这次想听听您办案的日常和痛点, 聊 60-90 分钟, 不会有任何产品推销。
> 我会做笔记, 匿名整理到产品文档, 您可以随时让我停。

**核心原则**:
- 不卖产品, 不承诺
- 让律师先说痛点, 再聊产品
- 重要的话记到引号里, 后面会反复引用

---

## 一、执业背景 (热身, 5 分钟)

1. **执业年限和团队规模**
   - 您执业多少年了? 团队几个人?
   - 主要业务方向? (民商/刑事/行政/家事/知识产权/公司...)
   - 一年大概接多少案件?

2. **典型的一天怎么过?**
   - 早上 / 下午 / 晚上分别做什么?
   - 案牍 (写文书) 大概占一天多少时间?

---

## 二、痛点深挖 (核心, 30 分钟)

3. **最头疼的 3 件事 (开放式)**
   > "如果明天醒来, 您的执业生活中有三件事能自动消失, 您最希望是哪三件?"
   - 让律师自己排序, 记录他的 Top 3
   - **追问**: 这三件事每周花你多少时间?

4. **文书痛点** (针对起草/审查)
   - 写一份起诉状/答辩状/合同, 从零到定稿一般要多久?
   - 文书最难的是哪一步? (思路/法条引用/格式/措辞/...)
   - 模板从哪来? (自己存/律所统一/网上下载/同行分享)
   - 同一类型文书 (比如买卖合同纠纷起诉状), 不同案子的复用率大概多少?

5. **类案检索痛点**
   - 类案检索一般用什么工具? (裁判文书网 / Alpha / 元典 / 北大法宝 / ...)
   - 一次典型检索花多久? 检索到的案子和本案的匹配度?
   - 最希望类案检索能给你什么? (更准 / 更全 / 附带裁判思路 / 法官倾向分析 / ...)

6. **证据痛点** (针对证据目录/证据链)
   - 一份典型案件的证据材料多少份? 整理成证据目录要多久?
   - 证据目录现在怎么写? 痛点在哪?
   - 排过证据目录错位、证明目的写不准的坑吗?

7. **客户沟通痛点**
   - 一天回多少条客户微信/电话?
   - 最怕被问到什么? (费用/时间/胜诉概率/...)
   - 客户催 / 客户情绪化 / 客户中途改诉求, 哪个最头疼?

8. **流程痛点** (开庭/立案/期限)
   - 排庭/开庭准备, 哪一步最耗时间?
   - 错过/记错期限的教训有吗? (程序性失误)
   - 庭前会议、证据交换这类流程, 有没有工具能帮你?

---

## 三、工具现状 (10 分钟)

9. **现在用的工具清单**
   - 案牍: Word / WPS / 腾讯文档 / 其他?
   - 检索: Alpha / 元典 / 北大法宝 / 无 / 多?
   - 律所管理: iCourt / 律赢 / 无 / 自研表格?
   - 日程: Outlook / 微信提醒 / 飞书 / 纸质 / 其他?
   - 客户管理: Excel / 微信 / 律所CRM / 无?
   - AI 工具: ChatGPT / Kimi / 文心 / 豆包 / 没用过?

10. **付费情况**
    - 现在为哪些工具付费? 一年大概多少钱?
    - 哪款工具是 "钱花在刀刃上"? 哪款是 "将就用"?
    - 不用 / 弃用过哪些工具? 为什么?

---

## 四、预算与付费意愿 (10 分钟)

11. **每月工具预算**
    - 团队/个人每月能花在 "工具提效" 上的钱大概多少?
    - 工具预算的拍板权在您手里吗? (个人/合伙人/财务)

12. **什么样的价格会觉得值?**
    - 假设一款工具能帮您把案牍时间减半, 您觉得每月付多少合理?
    - 年付一次性 vs 月付, 倾向哪种?
    - **追问**: 您试用过哪些 SaaS 觉得贵? 觉得便宜?

13. **对 "本地化" "隐私" 的态度**
    > 我们的产品所有数据存在您自己电脑上, AI 在本地跑
    - 这对您是加分项 / 减分项 / 无所谓?
    - 有没有因为数据安全原因放弃过某些 SaaS?
    - 您会把客户敏感信息传到 ChatGPT 这种工具吗?

---

## 五、对 LexPrime 的初步反应 (15 分钟)

> **产品演示 (5 分钟)**: 现场展示本地化部署 + 文书草拟 + 证据目录生成 + 类案参考 (用录屏/截图, 不强求)

14. **演示后的第一反应**
    - "这东西对您有什么用?" (最有用和最没用的部分)
    - "跟 Alpha / 元典比, 最大的差别是什么?"
    - **追问**: 如果这产品下周上线, 您愿意试 30 天免费吗? 试完可能付费吗?

15. **改进建议与最不靠谱的担心**
    - "您觉得哪里还差得远? / 哪里最鸡肋?"
    - "最担心它出什么毛病?" (答错/丢数据/慢/...)
    - "如果只能改一个地方, 您希望改哪里?"

---

## 六、收尾 (5 分钟)

16. **开放追问**: "还有什么想跟我说的, 我没问到的?"

17. **后续安排**:
    - 内测 30 天免费试用邀请 (手卡 / 邮件 / 微信)
    - 后续可以加微信/邮箱保持联系
    - 介绍朋友/同事 (同类型 1-2 位, 帮引荐)
    - **约下一位律师**: 律师朋友引荐 (滚动获客)

**送客礼**: 一份类案大数据报告 PDF (产品自身生成) + 30 天免费试用卡

---

## 附录: 访谈记录规范

每场访谈结束后 24 小时内, 总指挥把录音/笔记转给产品经理, 产品经理整理出:

| 字段 | 必填 | 说明 |
|---|---|---|
| 律所基本信息 | ✅ | 名称/规模/业务方向/团队 |
| 痛点 Top 5 (按严重度排序) | ✅ | 用律师原话引述, 标注每周耗时 |
| 当前工具与付费 | ✅ | 工具名 + 年费 + 评价 |
| 预算与付费意愿 | ✅ | 月预算 + 决策权 + 价格预期 |
| 内测意愿 | ✅ | Y/N + 时间 + 特殊要求 |
| 引荐可能 | ✅ | 律师朋友名单 |
| 关键引言 (金句) | ✅ | ≥3 句, 后续做产品文案用 |
| 风险与顾虑 | ✅ | 弃用原因 / 数据安全担忧 |
| 行动项 | ✅ | 24h 内发邀请 / 1 周后回访 / 介绍朋友 |

> **核心原则**: 律师的痛点用律师的话写, 不要美化。不要 "我觉得他是想表达 XXX", 直接引述。
