## 2. 评审流程详细 (100 分钟)

### 2.1 段 1: 开场 (14:00 - 14:05, 5 min)

**主持人**: 总指挥

**议程**:
1. (0-1 min) 总指挥开场:
   > "各位律师好, 感谢参加 LexPrime Skill 2 合同风险审查律师评审. 我是 LexPrime (元枢法智) 的产品负责人 42081, 今天陪同的是我们的产品经理 (PM 在线)."

2. (1-3 min) 3 律师 (评审 #1) / 2 律师 (评审 #2) 自我介绍:
   - 姓名 + 律所/公司 + 执业年限 + 专业领域
   - 简述业务量 (合同审查 件/月)

3. (3-4 min) 评审流程介绍:
   - 100 分钟分段 (开场 5 + 演示 15 + 试审 30 + Q&A 20 + 评分 15 + 茶歇 15)
   - 评分维度 (D1 三级识别 + D2 修改建议 + D3 谈判策略 + D4 中立性 + D5 UI 流程)
   - 评分量表 (1-5 分) + 综合门槛 ≥ 4.0

4. (4-5 min) 中立性硬约束 (PRD §5.7):
   - "Skill 2 输出严禁'必败/必胜/胜诉率 X%' 等确定性表述"
   - "评审中如发现违规, 请立即指出, 我们会立即停止评审并修复"

**PM 动作**: 实时记录律师自我介绍 + 计时 5 分钟

**预期产出**: 律师基本信息确认 (姓名/律所/执业年限) → 更新 lawyer-profiles-w6.md

---

### 2.2 段 2: Skill 2 UI 演示 (14:05 - 14:20, 15 min)

**主持人**: 总指挥 (操作 Skill 2)

**议程**:
1. (0-3 min) 上传合同 (演示页面 01-upload):
   - 选 1 份测试合同 (租房合同) 上传
   - 展示 OCR 自动识别 (PaddleOCR, W5 Track B 部署)
   - 律师提问: "OCR 准确率如何? 扫描件 / 表格支持吗?"

2. (3-6 min) 风险高亮 (演示页面 02-review-result):
   - 展示致命红/重大黄/建议蓝 三级颜色高亮
   - 红黄绿灯汇总 (5 合同整体风险)
   - 律师提问: "颜色对比度够吗? 律师色盲比例约 8%"

3. (6-9 min) 修改建议 (演示页面 03-suggestion-detail):
   - 展示 fatal/major 的修改建议 + modified_clause_template
   - 法条引用 (民法典 + 民诉法 + 最高法司法解释)
   - 律师提问: "modified_clause_template 一键替换准确率?"

4. (9-12 min) 谈判策略 (演示页面 04-negotiation):
   - 展示 priority_clauses + leverage_points + walk_away_signals
   - 立场感知 (甲方/乙方/丙方/审查方)
   - 律师提问: "立场感知准确率? 跨立场会混淆吗?"

5. (12-15 min) 导出 + 总结 (演示页面 05-export):
   - 导出格式 (Word / PDF / Markdown / 飞书文档)
   - 审计日志 (谁审了 + 时间 + 版本)
   - 律师提问: "导出格式能定制吗? 公司有模板"

**PM 动作**: 录屏 + 记录律师提问 + 截图关键 UI 节点

**预期产出**: 律师对 Skill 2 UI 的第一印象 → review-summary-w6.md §2

---

### 2.3 段 3: 5 测试合同试审 (14:20 - 14:50, 30 min)

**主持人**: 总指挥 (监督 + 答疑)

**议程**:
1. (0-2 min) 律师分工:
   - 3 律师 (评审 #1) 各自独立审查 5 合同
   - 律师按 review-template.md §5.1-§5.5 per 合同填表 (fatal/major/advisory/ok + 跟 Skill 一致?)
   - 5 合同: 租房 (8 min) + 借款 (8 min) + 劳动 (5 min) + 服务 (5 min) + 销售 (4 min) = 30 min

2. (2-30 min) 律师独立审查:
   - 律师在自己电脑上人工审查 5 合同
   - 输出自己的风险标注 + 跟 Skill 2 baseline 对比
   - 标注差异原因 (法条引用 / 行业惯例 / 风险等级边界)
   - 总指挥 + PM 在线答疑

**PM 动作**: 实时记录律师试审过程 (哪个合同耗时最长 + 哪个差异最大)

**预期产出**: 5 律师 × 5 合同 = 25 份 per 合同评审表 → lawyer_review_skill2_*.md §5

### 2.4 段 4: Q&A 题库 (14:50 - 15:10, 20 min)

**主持人**: 总指挥 (按 review-questions-w6.md §1-§5 顺序逐维提问)

**议程**:
1. (0-4 min) D1 三级识别准确率 (5 问):
   - Q1 [L1] 致命风险识别 (租房合同)
   - Q6 [L2] 重大风险识别 (借款合同)
   - Q11 [L3] 建议风险识别 (服务合同)
   - Q16 [L4] 综合三级 + 批量
   - Q21 [L5] 致命漏检审计

2. (4-8 min) D2 修改建议实用性 (5 问):
   - Q2 [L1] 修改建议可执行性
   - Q7 [L2] 修改建议覆盖度
   - Q12 [L3] 修改建议表述专业性
   - Q17 [L4] 修改建议行业适配
   - Q22 [L5] 修改建议法条准确性

3. (8-12 min) D3 谈判策略可执行性 (5 问):
   - Q3 [L1] 谈判策略优先级
   - Q8 [L2] 谈判策略筹码描述
   - Q13 [L3] 谈判策略红线识别
   - Q18 [L4] 批量谈判策略汇总
   - Q23 [L5] 跨部门谈判策略

4. (12-16 min) D4 LLM 输出中立性 (5 问):
   - Q4 [L1] "胜诉率" 表述审查
   - Q9 [L2] "司法保护" 表述审查
   - Q14 [L3] "建议争取" 表述审查
   - Q19 [L4] 立场感知中立
   - Q24 [L5] 合规风险表述

5. (16-20 min) D5 UI 流程合理性 (5 问):
   - Q5 [L1] 5 步内完成审查
   - Q10 [L2] 团队协同 UI
   - Q15 [L3] 客户友好型 UI
   - Q20 [L4] 批量审查 UI
   - Q25 [L5] 私有化部署 UI

**每律师 4 分钟**: 1 问 (3-4 min) + 追问 (0-1 min), 律师口头答 + 同步在 review-template §6-§10 填分

**PM 动作**: 实时记录每律师答 + 填分

**预期产出**: 25 问 × 律师评分 → lawyer_review_skill2_*.md §6-§10

### 2.5 段 5: 律师评分填写 (15:10 - 15:25, 15 min)

**主持人**: 总指挥 (答疑 + 收表)

**议程**:
1. (0-2 min) 评分填写说明:
   - 律师按 review-template.md §6-§10 填分 (D1/D2/D3/D4/D5)
   - 综合评分自动计算 (0.30×D1 + 0.25×D2 + 0.20×D3 + 0.15×D4 + 0.10×D5)
   - 通过门槛: 综合 ≥ 4.0 + D1 ≥ 4.25 + D4 = 5

2. (2-12 min) 律师独立填表:
   - 律师在自己电脑上填表 (review-template.md)
   - 或用纸质评分表 (总指挥备的)
   - 总指挥 + PM 在线答疑

3. (12-15 min) 评分回收:
   - 律师发 review-template.md 给总指挥邮箱 (privacy@lexprime.com)
   - 或拍照发微信 (总指挥微信)
   - 总指挥确认收到

**PM 动作**: 实时记录评分 + 汇总到 review-summary-w6.md

**预期产出**: 5 份 review-template.md 评分完整版 → lawyer_review_skill2_*.md

## 5. 评审现场应急处理

### 5.1 常见问题预案

| 应急场景 | 触发条件 | 处理方案 |
|---|---|---|
| **网络故障** | 腾讯会议断开 ≥ 5 min | (1) 总指挥立即重连 (2) 备用网络 (4G) (3) 改电话评审 + 录屏 |
| **律师迟到** | 律师晚到 ≥ 10 min | (1) 其他律师先开始 (2) 律师到后补流程 (3) 缩短茶歇 |
| **律师提前退出** | 律师提前 ≥ 20 min 退出 | (1) 录音已留底 (2) 律师后续 email 补评分 (3) 评价按现场已填部分 |
| **律师不熟悉 Skill 2** | 律师评审中还在问基础 | (1) 总指挥延长演示到 20 min (2) 律师试审时间压缩到 20 min |
| **中立性违规** | 评审现场发现 1 处违规 | (1) 立即停止评审 (2) lex-ai 修复 language_guard (3) 律师复评 |
| **致命漏检争议** | 律师跟 baseline 差异 ≥ 2 fatal | (1) 详细讨论 (2) 律师标注 + 差异原因 (3) 不影响评审通过, 后续 W7 改进 |
| **评审超时** | 100 min 不够, 延到 17:00 | (1) 茶歇缩短到 5 min (2) 评分压缩 (3) 总指挥决定是否分 2 天 |

### 5.2 关键注意事项 (PM 自检)

- ✅ 中立性硬约束: 评审中如发现"必败/必胜" 立即停止
- ✅ 数据安全: 评审律师不能上传真实客户合同, 仅用测试合同 baseline
- ✅ 录屏必须开: 腾讯会议自带 + OBS 备用, 律师同意录音
- ✅ 评分表回收: 律师当场发总指挥邮箱或拍照微信
- ✅ 律师签字: review-template.md §14 必须签, 不签的按"弃权" 处理
- ✅ 引荐 #R3/#R4: 评审 #1 后, 律师可能引荐下一批律师

## 7. 风险与回退

| 风险 | 触发条件 | 回退方案 |
|---|---|---|
