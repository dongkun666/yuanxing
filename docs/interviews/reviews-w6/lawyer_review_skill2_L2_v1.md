## 3. Q&A 题库回答 (review-questions-w6.md §1-§5)

> **数据状态**: [PRD 假设预填, 待 07-19 真实 Q&A 数据覆盖]

### 3.1 D1 三级识别准确率 (Q2)

**问题**: 在个人借款合同 baseline 中, Skill 2 标出 clause 3 (利息) 利率超过 LPR × 4 倍为 major, 担保条款又约定了"逾期利息 + 违约金 + 罚息" 三重叠加. 请问您认为 Skill 2 是否正确识别了"三重叠加" 的隐性风险? 您在实务中会怎么标注?

**L2 回答**: [PRD 假设预填]
> "Skill 2 正确识别了'三重叠加' 风险, 这是隐性风险中最容易忽略的. 我在实务中会判 major + 引用最高法民间借贷司法解释第 30 条: '出借人与借款人既约定了逾期利率, 又约定了违约金或者其他费用, 出借人可以选择主张逾期利息、违约金或者其他费用, 也可以一并主张, 但总计超过年利率 24% 的部分, 人民法院不予支持.' 律师客户看到这个会立刻理解. 但 Skill 2 baseline 标 fatal (Skill 标 clause 5 担保叠加为 fatal, 实际应 major), 略有高判. 我会给 4.0/5."

### 3.2 D2 修改建议实用性 (Q7)

**问题**: 在个人借款合同 baseline 中, Skill 2 对 fatal/major 4 处全部给了修改建议, 其中 3 处带 modified_clause_template. 请问作为小所主任, 您审这类合同时, 这种"致命 100% 覆盖"对您价值大吗? 您希望建议覆盖到什么程度?

**L2 回答**: [PRD 假设预填]
> "100% 覆盖价值大, 作为主任我每周审 20+ 合同, 致命 100% 覆盖能节省 30-50% 审核时间. 但 modified_clause_template 只有 60-80% 可用, 因为: (1) 模板偏模板化, 跟具体案情脱节 (2) 缺地方高院裁判口径 (3) 缺行业惯例 (4) 缺律师执业习惯适配. 我希望覆盖度 = fatal 100% + major 80% (主流风险) + advisory 30% (细节优化), modified_clause_template 80% 可用 (按行业 / 标的 / 复杂度 分版本)."

### 3.3 D3 谈判策略可执行性 (Q12)

**问题**: 在借款合同 baseline 中, Skill 2 给出 leverage_point "对方担保物价值 200 万, 借款金额 50 万, 担保覆盖充足, 可要求降低利率". 请问这种"数据 + 理由" 描述, 您在谈判时能用得上吗? 需不需要补充"谈判话术"?

**L2 回答**: [PRD 假设预填]
> "数据 + 理由描述直接用, 律师补充 1 句开场白即可: '对方担保物价值 200 万, 我们借款 50 万, 担保覆盖 4 倍, 我方认为利率应从 24% 降至 LPR × 2 倍 (≈ 7%), 这是合理诉求'. 不需要补充完整话术, 律师本人有谈判风格. 但 Skill 2 应补充'让步区间' 维度 (24% → 7% → 5% 三档, 标注每档可接受条件), 让我跟客户沟通时有'底线 + 目标 + 退路' 三层."

### 3.4 D4 LLM 输出中立性 (Q17)

**问题**: 在借款合同 baseline 中, Skill 2 给出"按 LPR × 1.5 倍司法保护上限" 表述, 请问这种表述准确吗? 律师客户看到"司法保护" 这种字眼, 会不会误解为"胜诉保证"?

**L2 回答**: [PRD 假设预填]
> "表述准确, '司法保护上限' 跟'胜诉保证' 是两个概念. '司法保护上限' 是法院判决时参照的标准, 不是判决结果. 律师客户能区分, 普通客户可能误解, 我会口头解释 1 句: '司法保护上限是法院判决时的参照标准, 不是说一定能拿到这么多'. Skill 2 表述 OK, 但建议补充免责声明: '本表述仅供参考, 最终以法院判决为准'."

### 3.5 D5 UI 流程合理性 (Q22)

**问题**: 假设您是 L2 小所主任, 您和 3 位授薪律师共用 Skill 2. 请问当前 UI 是否支持"主任派单 + 授薪审查 + 主任审核" 协同场景? 是否需要"任务分配 + 进度看板 + 风险汇总" 模块?

**L2 回答**: [PRD 假设预填]
> "当前 UI 不支持团队协同, 这是 Skill 2 最大的 P0 缺陷. 我作为主任, 1 周有 10-15h 在审核授薪律师的合同, 急需: (1) 任务分配 (主任派单给授薪, 授薪审查, 主任审核) (2) 进度看板 (谁审了什么, 进度如何) (3) 风险汇总 (本月 50+ 合同, 致命/重大风险 Top 10) (4) 主任一键审核 (授薪审查后, 主任直接看到致命条款一键 approve/reject). 当前 UI 是单用户版, 急需扩展团队版."
