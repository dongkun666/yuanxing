## 3. Q&A 题库回答 (review-questions-w6.md §1-§5)

> **数据状态**: [PRD 假设预填, 待 07-19 真实 Q&A 数据覆盖]

### 3.1 D1 三级识别准确率 (Q3)

**问题**: 在 App 开发服务合同 baseline 中, Skill 2 在 clause 4 (知识产权归属) 标了 1 个 advisory (源码归属表述模糊). 律师您在婚姻家事业务中, 类似条款 (如夫妻共同财产协议中的产权归属) 也会出现模糊表述. 请问您对这种"advisory" 级别提示是怎么看的? 律师客户能接受吗?

**L3 回答**: [PRD 假设预填]
> "advisory 级别提示必要, 但 Skill 2 标得太弱. 我在婚姻家事业务中, 财产协议的产权归属模糊会引发继承纠纷 (例如离婚后前配偶主张产权), 律师客户期望的不是 advisory 提示, 而是 major 提示 + 强制要求客户补充'产权归属 + 交付物清单 + 异议期'. Skill 2 应调整分级标准: '产权归属模糊' 在不同行业 (IT/婚姻家事) 风险等级不同, 应按行业上下文动态调整. 婚姻家事场景下, 应升判 major."

### 3.2 D2 修改建议实用性 (Q8)

**问题**: 在 App 开发服务合同 baseline 中, Skill 2 对 clause 5 (验收条款) 给出修改建议"补充验收标准 + 验收期限 + 验收异议期". 您认为这种"具体表述 + 时间数字" 的建议, 律师客户 (尤其婚姻家事当事人) 能理解吗? 需不需要补充"通俗解释"?

**L3 回答**: [PRD 假设预填]
> "修改建议方向对, 但需要补充'通俗解释' 律师客户能理解, 但婚姻家事当事人 (普通市民) 经常看不懂. 例如 '验收异议期' 当事人会问'异议期是什么意思? 14 天内我要做什么?' 建议 Skill 2 增加 1 栏'客户通俗版' (隐藏法条 + 突出风险 + 加白话解释), 律师可以一键切换'律师版'/'客户版'. 客户版对婚姻家事律师特别重要, 因为 50%+ 案件涉及情绪化客户, 律师需要直白解释."

### 3.3 D3 谈判策略可执行性 (Q13)

**问题**: 在服务合同 baseline 中, Skill 2 给出 walk_away_signal "验收不通过超过 3 次 = 对方违约, 可终止合同". 请问在您婚姻家事业务中, 类似"红线识别" (如对方出轨 = 可主张离婚 + 损害赔偿) 价值如何? AI 能自动识别吗?

**L3 回答**: [PRD 假设预填]
> "红线识别价值高, 但婚姻家事场景下需要定制模板. 我在婚姻家事业务中, 红线识别 (如对方出轨/家暴/赌博/转移财产) 决定案件策略, AI 自动识别能节省我 1-2h 案情分析. 但婚姻家事红线不像合同条款那样'客观' (条款白纸黑字), 而是从客户陈述中'主观' 提取 (例如客户说'对方经常晚回家' 暗示出轨). AI 需要定制婚姻家事模板: 客户陈述关键词匹配 + 情绪识别 + 客观证据交叉验证. 这是 Skill 2 后续可以扩展的方向, 但当前版本 v0.1 做不到."

### 3.4 D4 LLM 输出中立性 (Q18)

**问题**: 在服务合同 baseline 中, Skill 2 给出"建议争取知识产权归属" 的修改建议. 请问这种"建议争取" 的表述, 在您婚姻家事业务中, 律师客户可能解读为"一定能争取到" 吗? 需不需要改成"建议明确约定"?

**L3 回答**: [PRD 假设预填]
> "'建议争取' 表述模糊, 客户可能解读为'一定能争取到'. 律师自己不会误解, 但客户 (尤其婚姻家事当事人) 容易误解, 我在跟客户沟通时会口头修正: 'AI 建议争取知识产权归属, 实际意思是我们要明确约定, 这是双方协商的事, 不一定能争取到'. 建议 Skill 2 改为'建议明确约定知识产权归属', 表述更准确, 客户误解风险低. 这点 P0 改进, 影响客户体验."

### 3.5 D5 UI 流程合理性 (Q23)

**问题**: 婚姻家事律师经常要把合同 / 协议给客户 (非律师) 阅读. 请问 Skill 2 的"风险高亮 + 修改建议" UI, 客户 (普通市民) 能直接看懂吗? 是否需要"客户友好版" UI (隐藏法条 + 突出风险)?

**L3 回答**: [PRD 假设预填]
> "客户完全看不懂当前 UI. 当前 UI 是律师专用, 法条引用 + 修改建议都是律师语言, 客户 (普通市民) 看不懂, 反而会增加焦虑. 婚姻家事客户情绪化多, 看到'fatal 风险' 标签会非常紧张, 律师需要花 10-15 min 解释. 急需'客户友好版' UI: (1) 隐藏法条 (2) 突出风险 (用图标代替文字 fatal/major) (3) 加'客户白话解释' (例如'fatal = 这条对你很不利, 建议必须改') (4) 律师一键切换律师版/客户版. 这是 P0 改进, 婚姻家事场景必备."
