### 3.2 react-i18next 框架集成 (W24 本次)

```typescript
// mobile/ios/LetterMobile/i18n.ts + mobile/android/LetterMobile/i18n.ts + desktop/i18n.ts
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import zhCN from './locales/zh-CN.json';
import enUS from './locales/en-US.json';

i18n
  .use(initReactI18next)
  .init({
    resources: {
      'zh-CN': { translation: zhCN },
      'en-US': { translation: enUS },
    },
    lng: 'zh-CN', // 默认中文
    fallbackLng: 'en-US',
    interpolation: { escapeValue: false },
    // W24 多语言支持
    supportedLngs: ['zh-CN', 'en-US'],
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage'],
    },
  });

export default i18n;
```

> **react-i18next 13+ 框架 (W24 多语言核心)**:
> - **i18next 23+**: 律师函生成时多语言字符串 (zh-CN + en-US) 即时切换
> - **react-i18next 13+**: React Hook (useTranslation) + HOC (withTranslation) + Trans 组件
> - **i18next-browser-languagedetector**: 自动检测浏览器语言 (zh-CN / en-US)
> - **localStorage 缓存**: 律师语言偏好持久化 (重启 App 仍保留)
> - **资源懒加载**: 律师函生成时才加载对应语言资源 (降低启动时间 < 100ms)
> - **占位符插值**: 律师函字段 {{sender}} {{recipient}} {{date}} 多语言适配
