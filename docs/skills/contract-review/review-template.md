## 2. 评审方法 (PM 起草)

### 2.1 评审流程 (90 分钟)

```
00:00 - 00:10  开场 (5 分钟)
              - 律师自我介绍 + 业务背景
              - 评审流程 + 评分维度介绍

00:10 - 00:40  Skill 2 演示 (30 分钟)
              - 总指挥演示上传 → 审查 → 风险高亮 → 修改建议 → 谈判策略 → 导出
              - 重点展示 致命/重大/建议 三级颜色高亮 + 红黄绿灯
              - 律师现场提问 (Skill 边界 / 实用性 / 准确性)

00:40 - 01:10  5 合同独立审查 (30 分钟, 5 分钟/合同)
              - 律师人工审查 5 合同, 输出自己的 fatal/major/advisory 标注
              - 跟 Skill 2 输出对比, 标注差异
              - 填写 §5 测试合同评审表 (per 合同)

01:10 - 01:30  评分 (20 分钟)
              - 律师填写 §6 - §9 评分维度
              - 律师填写 §10 整体评分 + §11 关键发现 + §12 改进建议

01:30 - 01:40  收尾 (10 分钟)
              - 致谢 + 礼品 (类案报告 + 30 天免费试用 + 茶歇)
              - 律师签字 + 引荐 #R3 / #R4 (若有)
```

### 2.2 评审核心原则 (PRD § 5.4 Skill Hub 硬约束)

- **零确定性预测**: 评审中如发现 Skill 2 输出含"合同必败/必胜"等表述, 一票否决
- **多立场视角**: 律师按自己执业立场 (甲方/乙方/审查方) 评估, 不强求一致
- **实用导向**: 评估"律师能否用此 Skill 提升效率", 不只看技术指标
- **风险等级边界清晰**: 致命 = 显失公平 / 违法 / 重大遗漏, 重大 = 隐含义务 / 争议管辖不利, 建议 = 表述模糊 / 可优化

## 3. Skill 2 概览 (PM 起草, 律师可跳过此节)

### 3.1 Skill 2 定位 (PRD § 3.12.2 + § 5.4)

**合同风险审查** — 对律师上传的合同文本进行逐条审查, 输出:

1. **三级风险标注** (致命 / 重大 / 建议 / 合规)
2. **修改建议** (针对 fatal/major 必返, advisory 可选)
3. **谈判策略** (priority_clauses + leverage_points + walk_away_signals)
4. **版本比对** (上传两份合同, 逐条 diff 差异)

**立场感知**: 律师立场 (甲方/乙方/丙方/审查方) 影响审查重点 + 谈判策略方向。

### 3.2 关键差异 (vs Skill 1 类案检索)

| 维度 | Skill 1 (类案检索) | Skill 2 (合同审查) |
|---|---|---|
| 输入 | 案由 + 法院 + 标的 | 合同文本 + 立场 + 行业 |
| 输出 | 类案 + 统计 + 图表 | 风险标注 + 修改建议 + 谈判策略 |
| 核心算法 | metadata filter + 向量召回 | 条款拆分 + 三级分类 + 立场感知 |
| 风险维度 | 0 (纯中立统计) | 4 (致命/重大/建议/合规) |
| 立场相关 | ❌ 不区分 | ✅ 4 立场影响审查 |
| UI 形态 | 类案卡片 + 统计图表 | 风险高亮 + 建议弹窗 + 策略面板 |
| 律师评审 | 3 位 (民商/知产/刑事) | 5 位 (单飞/小所×2/中所/企业法务) |

### 3.3 验收标准 (来自 manifest.json § compliance)

| 验收项 | 目标 | 实际 (待评审) |
|---|---|---|
| 致命/重大/建议 三级识别准确率 | ≥ 85% | ___ (律师填) |
| 修改建议实用性 | ≥ 70% 律师认可 | ___ (律师填) |
| 谈判策略可执行性 | ≥ 65% 律师认可 | ___ (律师填) |
| LLM 输出中立性 (PRD § 5.7) | 0 违规 | ___ (律师填) |
| 律师评审人数 | ≥ 3 位 (≥ 5 位更佳) | 5 位 (2 场) |

## 4. 评审维度框架 (PM 起草, 律师评分在 §6-§9)

### 4.1 五大评分维度

| # | 维度 | 权重 | 评分项 | 评分细则见 |
|---|---|---|---|---|
| 1 | **三级风险识别准确率** | 30% | 致命/重大/建议 是否准确 | scoring-rubric.md §2 |
| 2 | **修改建议实用性** | 25% | 修改建议可执行 + 法条引用准确 + 律师真用得上 | scoring-rubric.md §3 |
| 3 | **谈判策略可执行性** | 20% | 优先级排序 + 筹码描述 + 红线识别 | scoring-rubric.md §4 |
| 4 | **LLM 输出中立性** | 15% | 0 违规"必败/必胜"等表述, 不替代律师判断 | scoring-rubric.md §5 |
| 5 | **整体可用性** | 10% | UI 易用 + 加载速度 + 导出格式 + 红黄绿灯 | scoring-rubric.md §6 |

### 4.2 评分量表 (1-5 分)

- **5 分 (优秀)**: 超出预期, 可立即商用
- **4 分 (通过)**: 达到预期, 律师愿意使用
- **3 分 (及格)**: 基本可用, 有改进空间
- **2 分 (不及格)**: 明显缺陷, 需重大调整
- **1 分 (失败)**: 完全不可用, 需重新设计

### 4.3 通过门槛

- **综合评分 ≥ 4.0/5.0**
- **致命/重大准确率 ≥ 85%** (硬门槛, 一票否决)
- **中立性 0 违规** (硬门槛, 一票否决)
- **实用性 ≥ 70% 认可** (软门槛, 触发 P0 改进)
- **谈判策略 ≥ 65% 认可** (软门槛, 触发 P1 改进)
