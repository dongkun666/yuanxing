## 2. Skill 4 v1 4 模块

### 2.1 模块 1: 谈判策略生成器 (LLM 调用 + 风险标注)

**输入**:
- 律师输入: 案件类型 (contract / dispute / settlement) + 对方角色 (lawyer / party / judge) + 期望结果 (conservative / moderate / aggressive)

**输出**:
- 3 套谈判策略:
  - **保守策略**: 最小化风险, 优先维持现状, 争取小让步
  - **中等策略**: 平衡风险与收益, 争取中等让步
  - **激进策略**: 最大化收益, 接受较大风险, 争取大幅让步
- 每套策略附带:
  - **风险标注**: W12 doc_workflow 5 状态机模式 (草案 / AI 评审 / 律师评审 / 当事人签字 / 归档)
  - **胜诉率预测**: 复用 W11 PRD V5.0 § 11 类案界面语言规范 (禁用"必胜", 用 "近 3 年本法院 87 件类似案件中支持原告 72 件 约 83%")
  - **建议谈判话术**: 律师可复制使用

**技术栈**:
- LLM 调用 (复用 W22 Rust 5x perf, 单请求 RTT ~100µs)
- Prompt 工程 (复用 W15 e3f0940 + W3d429cd Skill 3 v2.0 prompt 模式)
- 风险标注 API (复用 W12 829d25c doc_workflow 状态机)

### 2.2 模块 2: 模拟对方 (3 角色)

**输入**: 律师输入案件详情 + 选择对方角色

**输出**:
- **对方律师视角**: AI 模拟对方律师的策略 + 应对话术
- **对方当事人视角**: AI 模拟对方当事人的心理 + 应对话术
- **法官视角**: AI 模拟法官的裁判倾向 + 应对话术

**应用场景**:
- 庭审前演练 (5-10 轮反向博弈)
- 谈判前准备 (5-10 轮反向博弈)
- 复盘训练 (复盘历史谈判的失败模式)

**技术栈**:
- LLM 调用 (同 § 2.1)
- 案件数据接入 (W19 doc_gen_router 4 endpoint + W12 doc_workflow)

### 2.3 模块 3: 谈判风险预警 (实时监测)

**输入**: 律师开始谈判 + AI 实时监测谈判内容 (语音转文字)

**输出**:
- **实时风险预警**: 谈判中触发风险点时立即推送 (类似法官庭审提示)
- **风险类型**:
  - 同意对方不合理要求 (模拟对方律师已经过度让步)
  - 漏掉关键证据 (对方未提出但对自己有利)
  - 错过关键 deadline (合同关键时点 + 对方优势)
  - 情绪失控 (语言过于激烈)
  - 信息泄露 (无意中暴露底牌)

**技术栈**:
- 语音转文字 (W5 ocr_upload + W8 PaddleEngine, 复用 v3.0 多端)
- 实时监控 (W22 Rust 5x perf)
- 风险标注 (W12 doc_workflow 状态机)

### 2.4 模块 4: 谈判复盘报告 (完结后)

**输入**: 律师完结谈判 + 上传谈判记录 (视频/音频/文字)

**输出**:
- **谈判复盘报告** (~5KB):
  - 谈判时间 + 地点 + 参与方
  - 关键节点 + 风险点 + 应对
  - 5 维度评分 (事实 / 法律 / 主张 / 时效 / 后果)
  - 改进建议 (5-10 条)
  - 跟类似案件对比
- **律师学习曲线**: 跟踪 100 律师 / 月, AI 自动识别律师的优势 / 劣势

**技术栈**:
- 报告生成 (复用 W23 phase5-5-celebration 格式样板)
- LLM 调用 (复用 W22 Rust 5x perf)
- 5 维度评分 (复用 W21 6929cc1 Skill 3 v2.0 5 维度评分机制)
