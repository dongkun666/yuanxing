## 6. 邀请函视觉规范 (跟 W1 设计系统一致)

### 6.1 配色

| 元素 | 颜色 | 用途 |
|------|------|------|
| 主色 | `#165DFF` (brand) | CTA 按钮 / 链接 / Logo |
| AI 紫 | `#6C5CE7` (ai) | "AI 辅助" 标识 / 角标 |
| 微信绿 | `#07C160` (wechat) | 微信二维码 / 微信 CTA |
| 紧急橙 | `#FA8C16` (urgent) | 倒计时 / 80 席剩余 / 紧迫感 |
| 成功绿 | `#00B42A` (success) | 福利勾选 / 完成状态 |

### 6.2 文案规范

- **不用**: "立即购买" / "限时折扣" / "错过不再有" / "AI 自动办案" / "替代律师"
- **用**: "免费试用" / "30 天" / "无信用卡" / "AI 辅助" / "数据本地化"
- **称呼**: 一律用 "您" 不用 "你" (体现专业感)
- **律所/公司**: 首次出现用全称, 后续简称

### 6.3 图片规范

- **必须**: 真实产品截图 (workstation.html 主屏 + 类案 + 合同审查 3 张)
- **禁止**: 营销模板图 / 库存图 / AI 生成的"假截图"
- **格式**: PNG 高清, 宽度 1200px, 大小 < 500KB
- **命名**: `lexprime-workstation.png` / `lexprime-skill1-case.png` / `lexprime-skill2-contract.png`

### 6.4 二维码

- **公测链接**: 微信群发版配 1 张产品二维码 (指向 https://yuanxing.app/r/[专属链接])
- **创始人微信**: 1 对 1 / 邮件版配 1 张微信二维码 (建议新开工作号)
- **启动仪式腾讯会议**: 启动前 1 天 (7/25) 通过邮件 + 微信群发布
