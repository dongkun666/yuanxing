## 1. 5 步注册转化漏斗 (Trial Funnel)

### 1.1 漏斗结构 (5 步)

```
[Step 1] 访问 landing             beta_landing_pv            100%   (基线)
   ↓
[Step 2] 看定价 / 5 步流程         beta_pricing_view          60%+   (停留 ≥ 30s)
   ↓
[Step 3] 填邮箱 + 邀请码           beta_register_submit       50%+   (基于 step 2)
   ↓
[Step 4] 邮箱验证成功             beta_email_verified        85%+   (基于 step 3)
   ↓
[Step 5] 创建账号试用             beta_trial_started         95%+   (基于 step 4)
   ↓
[End]   试用 7 日激活              beta_7d_activated          50%+   (PM 假设, W12 验证)
   ↓
[End+]  30 日付费                  trial_to_paid              5%+    (W6 末目标)
```

### 1.2 事件字段 (5 步统一 schema)

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| `event` | string | 事件名 (上表) | `beta_register_submit` |
| `timestamp` | ISO8601 | 事件时间 | `2026-07-15T10:23:45+08:00` |
| `user_id` | string \| null | 律师 ID (注册后) | `lawyer_20260715_001` |
| `anonymous_id` | string | 匿名 cookie (注册前) | `anon_abc123` |
| `email_hash` | string | 邮箱 SHA-256 前 16 位 (隐私) | `a3f2e1b9c8d4f5a6` |
| `invite_code` | string \| null | 邀请码 (注册时) | `BETA2025-0001` |
| `invite_channel` | enum | review / wechat-group / founding-member | `review` |
| `source` | enum | landing / 微信 / 邮件 / 朋友圈 | `landing` |
| `referrer` | string | 来源 URL (utm_source) | `https://yuanxing.app/r/L1` |
| `device` | enum | mobile / desktop / tablet | `mobile` |
| `session_id` | string | 会话 ID (跨页面) | `sess_xxx` |
| `trial_tier` | enum | trial / pro | `trial` |
| `value` | float | 事件价值 (注册=0, 付费=¥899) | `0` |

### 2.2 Step 2: 看定价 / 5 步流程 (`beta_pricing_view`)

| 触达后行为 | 触发事件 | 律师心理 |
|------------|----------|----------|
| 滚动到 `#pricing` 模块 ≥ 30s | `beta_pricing_view` | "价格 OK, 看看 5 步流程" |
| 滚动到 `#workflow` 模块 ≥ 30s | `beta_workflow_view` | "5 步上手, 流程简单" |
| 滚动到 `#features` 模块 ≥ 30s | `beta_features_view` | "9 模块都有, 涵盖我需要的" |
| 滚动到 `#values` 模块 ≥ 30s | `beta_values_view` | "5 大价值主张有共鸣" |
| 滚动到底部 footer | `beta_footer_view` | "信任, 法务咨询" |
| 回到 `#register` 表单 | `beta_register_section_view` | "准备注册" |

> **Step 2 转化指标**: 60%+ 律师会停留 ≥ 30s 看到 #pricing 或 #workflow 模块

### 2.3 Step 3: 填邮箱 + 邀请码 (`beta_register_submit`)

| 字段 | 客户端校验 | 服务端校验 (invite_router) |
|------|------------|---------------------------|
| 邮箱 | HTML5 `type=email` | Pydantic `EmailStr` + 免费邮箱黑名单 |
| 邀请码 | HTML5 `pattern=BETA2025-[0-9]{4}` | Pydantic `INVITE_PATTERN` 正则 |
| 同意条款 | HTML5 `required` | 业务层校验 |
| 提交按钮 | `disabled` 防双击 | API 限流 10/min/email |

| 校验失败 | HTTP 状态 | 错误码 | 用户提示 |
|----------|-----------|--------|----------|
| 邀请码格式错 | 422 | `code_invalid_format` | "格式: BETA2025-XXXX" |
| 邀请码不存在 | 404 | `code_invalid` | "邀请码无效, 请检查" |
| 邀请码已用 | 409 | `code_used` | "1 码 1 用, 请联系邀请人" |
| 邀请码过期 | 410 | `code_expired` | "公测期 7/15 - 8/9" |
| 邮箱免费域名 | 422 | `email_invalid` | "请用律师工作邮箱" |
| 提交过频 | 429 | `rate_limit` | "稍后再试" |

### 2.4 Step 4: 邮箱验证成功 (`beta_email_verified`)

| 行为 | 触发事件 | 备注 |
|------|----------|------|
| 收件箱收到验证码 (6 位) | `beta_email_sent` | SMTP 发出 |
| 律师输入验证码 | `beta_otp_input` | 6 位数字 |
| 验证码正确 | `beta_email_verified` | POST /api/auth/verify-email |
| 验证码错误 | `beta_otp_fail` | 限 5 次/小时 |
| 验证码过期 (>10 min) | `beta_otp_expired` | 重新发送 |

> **Step 4 转化指标**: 85%+ (验证码 1 步到位)

### 2.5 Step 5: 创建账号试用 (`beta_trial_started`)

| 行为 | 触发事件 | DB 操作 |
|------|----------|---------|
| 验证码通过 | `beta_trial_started` | INSERT INTO auth_users (subscription_tier='trial', trial_started_at=NOW()) |
| 进入 Onboarding 5 步 | `onboarding_started` | UPDATE auth_users.onboarding_step=1 |
| 完成 Step 1-2 | `onboarding_partial` | onboarding_step=2 (基础激活) |
| 完成 Step 3-4 | `onboarding_active` | onboarding_step=4 (激活, 优先客服徽章) |
| 完成 Step 5 全部 | `onboarding_complete` | onboarding_step=5 (完美激活, 创史体验官候选) |
| 试用 7 日 | `trial_7d_retained` | 计算 NOW() - trial_started_at |
| 试用 30 日 | `trial_30d_reached` | 计算 trial_started_at + 30 |
| 付费转化 | `trial_to_paid` | UPDATE subscription_tier='pro' |

> **Step 5 转化指标**: 95%+ 验证后立即创建账号
