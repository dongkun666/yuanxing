### 2.1 trial_expired 事件定义 (W11 C1 新增)

> 触发位置: 律师 30 天试用到期当天 00:00 (后端 cron job 扫描 trial_expires_at)
> 触发代码 (后端):
> ```python
> async def check_trial_expiry(db: AsyncSession = Depends(get_db)):
>     today = datetime.now(CST).date()
>     expired_trials = await db.scalars(
>         select(Trial).where(
>             Trial.expires_at <= today,
>             Trial.status == "active",
>             Trial.converted_to_paid == False
>         )
>     )
>     for trial in expired_trials:
>         trial.status = "expired"
>         await track_event(db, event="trial_expired", user_id=trial.user_id,
>                           trial_id=trial.id, trial_expires_at=trial.expires_at,
>                           days_since_trial=30, invite_code=trial.invite_code,
>                           channel=trial.channel)
>         await trigger_paywall(db, user_id=trial.user_id)
>     return {"expired_count": len(expired_trials)}
> ```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| event | string | 是 | 固定 trial_expired |
| user_id | string | 是 | 用户 UUID |
| trial_id | string | 是 | 试用记录 ID |
| trial_expires_at | timestamp | 是 | 试用到期时间 (注册 + 30 天) |
| days_since_trial | int | 是 | 试用天数 (固定 30) |
| invite_code | string | 是 | 邀请码 (BETA2025-XXXX) |
| channel | string | 是 | 渠道 (review / wechat-group / founding-member / bar-association / public) |
