## 5. 刑事律师特别建议

1. **刑事案件数据脱敏必做**: 立即在 Case 模型导入 / 输出时调用 `core/sanitize.py` 的脱敏函数, 否则可能泄露当事人信息
2. **量刑参考应单独优化**: 刑事案件律师更关心"量刑" 而非"判赔", 建议加 `punishment_reference` 字段 (类似 `amount_stats` 但针对刑期)
3. **二审改判率统计**: 刑事二审改判率是核心指标, 建议在 yearly_breakdown 外加 `appeal_reversal_rate` 字段
4. **法律援助 vs 委托辩护**: 区分强制辩护 / 委托辩护, 不同辩护类型的胜诉率差异大
5. **证据链完整性提示**: 刑事案件高度依赖证据链, Skill 应能根据案情提示"建议补充 X 类证据"

(以上建议可在 Phase 4.5+ 迭代)
