## 5. 知产律师特别建议

1. **知产案由应单独优化**: 知产案件 (专利 / 商标 / 著作权) 案由比较细分, 建议在搜索时也支持子分类 (例如"发明专利侵权" / "实用新型专利侵权")
2. **加入"等同原则" / "禁止反悔" 等知产专属标签**: 知产案件争议焦点比较特殊, 应有专门 tag
3. **关联"专利复审委员会" / "商标局" 决定**: 知产案件常引用行政决定, 应有 cross-reference
4. **技术调查官意见**: 知识产权法院有技术调查官, 应在法官卡片外加"技术调查官参与情况" 字段

(以上建议可在 W7 后续版本迭代中考虑)
