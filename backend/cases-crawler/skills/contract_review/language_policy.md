# Skill 2: 合同风险审查 — 界面语言规范 (Language Policy)

> **强制执行** · PRD § 5.4 横切面 4 Skill Hub + § 11 风险合规 硬约束 · 任何违反视为零容忍缺陷
> **校验工具**: `tests/test_contract_review_skill.py` + `language_guard.py`

---

## 1. 第一性原则

**合同审查 Skill 只输出"基于合同文本的客观风险描述与法律依据", 不输出"对该合同未来结果的确定性判断或预测"。**

| 类型 | 例 |
|---|---|
| **客观描述型** (✅ 允许) | "该条款逾期违约金约定为月租金 5%/日, 年化约 1825%, 超出 LPR 四倍司法保护上限, 司法实践中通常被调减。" |
| **判断/预测型** (❌ 禁止) | "本合同必败" / "本合同必胜" / "该条款无效" / "对方将承担全部责任" |

---

## 2. 禁用词清单 (正则, 大小写不敏感)

### 2.1 "合同必败/必胜" 类 (FORBIDDEN_PHRASES_HIGH · 致命)

```regex
合同必败
合同必胜
合同必(?:赢|输|失败|无效)
该合同(?:必定|必然|一定|将会)(?:败|输|无效|胜|赢|失败|成功)
```

匹配则视为 **HIGH 违规** (致命), 直接 reject 重新生成。

### 2.2 "该条款无效/有效" 类 (FORBIDDEN_PHRASES_HIGH)

```regex
该条款(?:必定|必然|一定|将会)?(?:无效|有效)
该条款(?:一定|必定)?(?:会被)?(?:认定|判定|裁决)?(?:无效|有效)
该条款(?:违反|违背)法律(?:无效|当然无效|自始无效)
```

匹配则视为 **HIGH 违规**。注意: 允许描述 "司法实践中通常被认定无效" 或 "存在被认定无效的风险" (有条件 / 概率性表述)。

### 2.3 "对方将承担/败诉" 类 (FORBIDDEN_PHRASES_HIGH)

```regex
对方(?:将|必定|一定|必然)(?:承担|败诉|输|赔偿)
(?:将|必定|一定|必然)(?:承担|败诉|输|赔偿)全部责任
应当(?:完全|全部)(?:承担|赔偿)
```

匹配则视为 **HIGH 违规**。

### 2.4 "该合同无效/有效" 类 (FORBIDDEN_PHRASES_HIGH)

```regex
本合同(?:一定|必定|必然|将会)?(?:无效|有效|可撤销|可变更)
```

匹配则视为 **HIGH 违规**。允许: "本合同可能存在效力瑕疵" / "本合同存在被认定无效的风险"。

### 2.5 "司法实践一定会..." 类 (FORBIDDEN_PHRASES_HIGH)

```regex
司法实践中(?:一定|必定|必然|百分百|绝对)(?:会|将|判定|认定)
法院(?:一定|必定|必然|百分百|绝对)(?:会|将|判定|支持|采纳)
```

匹配则视为 **HIGH 违规**。允许: "司法实践中通常..." / "类似案例中, 法院一般..."

### 2.6 LOW 违规 (建议修改, 不强制 reject)

```regex
我认为
我觉得
可能(?:会|将)?(?:败诉|无效|胜诉)
```

匹配则视为 **LOW 违规** (建议重新生成或人工编辑)。

## 3. 强制模板 (用于降级生成)

当 LLM 输出 narrative 反复违规 (3 次), 用以下模板降级:

### 3.1 clause_reviews[].risk_description 模板 (合规改写)

```
"该条款约定 [条款摘要]。在 [法条 / 司法解释] 框架下, 此类约定 [客观风险描述: 司法实践中通常被调减 / 存在效力瑕疵 / 可能被认定为显失公平 等]。"
```

### 3.2 risk_summary.narrative 模板

```
"本合同共审查 [N] 个条款, 其中存在 [fatal] 个致命风险条款, [major] 个重大风险条款, [advisory] 个建议风险条款。"
"具体风险: [top_risk_categories 列表]。"
"以上仅为基于合同文本的客观风险标注, 不构成法律意见, 不替代律师判断。"
```

### 3.3 negotiation_strategy.stance_specific_advice 模板

```
"[甲方/乙方/审查方] 立场: 重点关注 [priority_clauses] 条款, 建议优先协商 [leverage_points] 所列条款, 必要时考虑 [walk_away_signals] 提示的红线条款。"
```

### 3.4 version_diff.summary 模板

```
"对比版本 [baseline] 与版本 [compared], 共新增 [X] 个条款, 删除 [Y] 个条款, 修改 [Z] 个条款。"
"风险等级变化: [old → new 列表]。"
```

## 4. 校验时机

| 时机 | 校验对象 | 违规处理 |
|---|---|---|
| **Pre-output** | LLM 生成的 risk_description / narrative / stance_specific_advice | 自动 reject, 重新生成 |
| **Post-output** | 最终 output 所有 narrative 字段 | reject + 记录违规次数 |
| **End-to-end** | UI 渲染前最终检查 | 替换为降级模板 |
| **W6 律师评审** | 抽样 100 条输出人工 review | HIGH 违规 ≥ 1 → 退回 lex-ai 修复 |

---

## 5. 验收标准

| 指标 | 目标 |
|---|---|
| 自动化检测违规率 | 0/1000 次输出 |
| 律师抽样违规率 | 0/100 次抽样 |
| LLM 拒答重生成次数 | ≤ 3 次 / 次输出 |

---

## 6. 与 Skill 1 的差异

| 维度 | Skill 1 类案检索 | Skill 2 合同审查 |
|---|---|---|
| 禁止表述 | "本案胜诉率" / "预计判赔 XX 元" | "合同必败" / "该条款无效" |
| 允许表述 | "样本中支持原告诉请的比例约 X%" | "司法实践中通常被调减" / "存在被认定无效的风险" |
| 风险承担主体 | 法院 (审理结果) | 当事人 (合同效力 / 违约责任) |
| 输出格式 | 统计数据 + 红黄绿灯 | 风险等级 + 修改建议 + 谈判策略 |
