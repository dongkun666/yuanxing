# 类案检索 Skill 界面语言规范 (Language Policy)

> **强制执行** · PRD § 5.7 横切面 7 硬约束 · 任何违反视为零容忍缺陷
> **校验工具**: `tests/test_language_guard.py` + `language_guard.py`

---

## 1. 第一性原则

**类案检索 Skill 只输出"已发生事实的统计", 不输出"对本案的判断或预测"。**

这条原则贯穿所有 narrative 字段。技术上, 输出永远是以下两类:

| 类型 | 例 |
|---|---|
| **统计型描述** (✅ 允许) | "近 3 年本法院 87 件类似案件中, 支持原告诉请 72 件 (约 83%)" |
| **判断/预测型描述** (❌ 禁止) | "本案胜诉率约 83%" / "预计本案判赔 XX 元" |

---

## 2. 禁用词清单 (正则, 大小写不敏感)

### 2.1 "胜诉率" 类 (FORBIDDEN_PHRASES_HIGH)
```regex
(?P<text>本案)?胜诉率[:\s]?\d
本场胜诉
预计.*胜诉
```

匹配则视为**HIGH 违规** (致命), 直接 reject 重新生成。

### 2.2 "预计/将会" 类 (FORBIDDEN_PHRASES_PREDICT)
```regex
预计本案
预计判赔
预计.{0,20}元
预计.{0,20}天
本案将会
本案可能
大概.{0,5}胜诉
```

匹配则视为**HIGH 违规**。

### 2.3 主观/评价类 (FORBIDDEN_PHRASES_OPINION)
```regex
该法官.{0,15}(好|坏|偏袒|不公|优秀|较差)
该法院.{0,15}(偏袒|不公|支持原告|支持被告)
该地区.{0,10}法院.{0,15}(好|坏|差)
```

匹配则视为**HIGH 违规**。

### 2.4 LOW 违规 (建议修改, 不强制 reject)
```regex
我觉得
我认为
一般来说.{0,30}胜诉
```

匹配则视为**LOW 违规** (建议重新生成或人工编辑)。

## 3. 强制模板 (用于降级生成)

当 LLM 输出 narrative 反复违规 (3 次), 用以下模板降级:

### 3.1 outcome_distribution 模板
```
"在 [N] 件样本中, 支持原告诉请 (含部分支持) [X] 件, 占 [Y]%。"
```

### 3.2 amount_stats 模板
```
"判赔金额中位数约 [M] 元, 四分位距 [Q1]-[Q3] 元, 极值范围 [Min]-[Max] 元。"
```

### 3.3 judge_style 模板
```
"该法官在 [N] 件 [案由] 样本中, 支持原告诉请的比例约 [P]%; 平均审理周期 [D] 天; 证据采信倾向 [T]。"
```

### 3.4 overall narrative 模板
```
"本检索基于 [N] 件 [案由] [地域] [时段] 的已公开裁判文书, 统计结果如下: [outcome_distribution] + [amount_stats] + [judge_style]。以上数据仅为统计结果, 不代表对本案结果的预测。"
```

---

## 4. 校验时机

| 时机 | 校验对象 | 违规处理 |
|---|---|---|
| **Pre-output** | LLM 生成的 narrative | 自动 reject, 重新生成 |
| **Post-output** | 最终 output.narrative | reject + 记录违规次数 |
| **End-to-end** | UI 渲染前最终检查 | 替换为降级模板 |
| **W8 律师评审** | 抽样 100 条输出人工 review | HIGH 违规 ≥ 1 → 退回 lex-ai 修复 |

---

## 5. 验收标准

| 指标 | 目标 |
|---|---|
| 自动化检测违规率 | 0/1000 次输出 |
| 律师抽样违规率 | 0/100 次抽样 |
| LLM 拒答重生成次数 | ≤ 3 次 / 次输出 |
